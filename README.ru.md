# DJI Live Bridge

Приложение для macOS, которое принимает RTMP-поток из DJI Fly на Mac в той же сети, показывает локальный предпросмотр через MediaMTX и передаёт картинку встроенной цепочке FFmpeg, которой не нужен OBS. Из одного изображения вы одновременно ведёте трансляцию в Instagram, TikTok и любое RTMP-направление — или используете его как виртуальную камеру в TikTok LIVE Studio.

## Установка

1. Скачайте свежий файл `.dmg` со страницы [Releases](https://github.com/tanerozel/dji-live-bridge/releases).
2. Перетащите **DJI Live Bridge** в папку **Программы**. Виртуальная камера работает только оттуда.
3. Установите FFmpeg, он не входит в комплект: `brew install ffmpeg`.

Приложение подписано и нотаризовано Apple, поэтому открывается без предупреждений.

**Требования:** Mac с Apple Silicon, macOS 13 или новее, FFmpeg/ffprobe 8.1.2 или новее в `PATH`.

## Трансляция в Instagram / TikTok

Вкладка `Трансляция` — это один экран с тремя шагами:

1. **Подключите дрон** — вставьте показанный адрес `rtmp://…/drone` в DJI Fly (путь: **GO FLY → Передача → Платформы трансляций → RTMP**) или нажмите `Попробовать с видеофайлом`. Шаг станет зелёным, когда придёт картинка.
2. **Куда транслировать?** — выберите Instagram, TikTok или свой RTMP и вставьте адрес сервера и ключ трансляции с платформы. В Instagram: instagram.com → Создать (+) → Прямой эфир. Instagram выдаёт новый ключ для каждого эфира; обновите его кнопкой `Обновить ключ` на карточке направления.
3. **Изображение и звук** — `Вертикально 9:16` (по умолчанию для Instagram и TikTok), кадрирование и необязательный микрофон. Выбор запоминается.

Кнопка `НАЧАТЬ ТРАНСЛЯЦИЮ` становится активной, когда выполнены три условия: локальный сервер, видео с дрона и выбранное направление. Во время эфира видно время, состояние каждого направления и объём отправленных данных; если одно направление отвалится, остальные продолжат работу. В Instagram нужно дополнительно нажать «Начать эфир» на их стороне, чтобы трансляция стала публичной.

Приложение не входит в аккаунты платформ и не нажимает за вас кнопки подтверждения.

## TikTok LIVE Studio (виртуальная камера)

Здесь не нужны ни адрес сервера, ни ключ трансляции:

1. На вкладке `TikTok LIVE Studio` один раз нажмите `Включить виртуальную камеру`.
2. Если macOS спросит, разрешите расширение в **Системных настройках → Основные → Объекты входа и расширения → Расширения камеры**.
3. Когда на карточке появится `Готова к запуску`, нажмите `Запустить виртуальную камеру`.
4. В TikTok LIVE Studio добавьте источник камеры и выберите **DJI Live Bridge Camera**.
5. Установите захват звука этого источника в `Нет` и выберите ровно один микрофон в главном аудиоуправлении LIVE Studio.

Эта камера намеренно передаёт только видео. Если заменить приложение в папке «Программы», macOS отключает расширение: нажмите `Запустить виртуальную камеру` ещё раз, кнопка сама запросит включение. Кнопка «Go Live» по-прежнему нажимается вручную в TikTok LIVE Studio.

## Языки и темы

Приложение доступно на английском, турецком, испанском, китайском, арабском, хинди, португальском, русском, французском, немецком и японском. При первом запуске оно следует языку системы, а если такого нет — использует английский. При арабском весь интерфейс переключается справа налево, а технические значения (адреса, порты, кодеки) остаются слева направо. Названия устройств, кодеки, протоколы и текст ошибок не переводятся, чтобы диагностика оставалась точной.

Доступны пять тем: Системная, Светлая, Тёмная, Полночь и Песок.

## Качество и безопасность

- Постоянные 30 кадров/с, 6 Мбит/с CBR, H.264 High и ключевые кадры каждые 2 секунды — как требует приём Instagram/Facebook. Предпочтение отдаётся аппаратному кодировщику VideoToolbox.
- При кадрировании `Всё изображение` пустое место заполняется размытой копией видео вместо чёрных полос.
- Картинка кодируется один раз, после чего MediaMTX отправляет её каждому включённому направлению отдельно.
- Каждый ключ трансляции хранится в отдельной записи связки ключей macOS. Ключи никогда не попадают в файл настроек, аргументы FFmpeg или журналы.

| Порт | Прослушивание | Назначение |
| --- | --- | --- |
| 1935 | Локальная сеть (`:1935`) | Приём RTMP из DJI Fly |
| 8554 | `127.0.0.1` | Чтение RTSP и публикация `/production` |
| 8889 | `127.0.0.1` | Предпросмотр WHEP |
| 8189 | `127.0.0.1` | WebRTC ICE UDP/TCP |
| 9997 | `127.0.0.1` | Control API MediaMTX |
| 9998 | `127.0.0.1` | Метрики MediaMTX |

Настройки: `~/Library/Application Support/DJI Live Bridge/` · Журналы: `~/Library/Logs/DJI Live Bridge/` · Секреты: связка ключей macOS
