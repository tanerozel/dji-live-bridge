So gehen Sie mit einer DJI-Drohne auf Facebook live

Von Taner Özel · Aktualisiert 2. Oktober 2026

Öffnen Sie auf facebook.com Live-Video → Streaming-Software (Facebooks Live Producer), kopieren Sie Server-URL und Stream-Schlüssel in ein Facebook-Ziel in Stream My Drone, senden Sie das Drohnenbild aus DJI Fly an die App, drücken Sie LIVE STARTEN und dann in Live Producer Live gehen. Facebook akzeptiert nur verschlüsseltes RTMPS, und das erledigt die App.

Kurz gesagt

  • Server-URL und Schlüssel kommen aus Live Producer: Live-Video → Streaming-Software.
  • Server-URL: rtmps://live-api-s.facebook.com:443/rtmp/ – Facebook verlangt RTMPS.
  • Facebook vergibt pro Sitzung einen neuen Schlüssel, außer Sie schalten einen dauerhaften Stream-Schlüssel ein.
  • Facebook braucht alle 2 Sekunden einen Keyframe; Stream My Drone sendet immer genau das.
  • Sie können in Ihrem Profil, auf einer Seite oder in einer Gruppe posten und gleichzeitig auf anderen Plattformen streamen.

Schritt für Schritt auf Facebook live gehen

  1. Drohne verbindenÖffnen Sie in DJI Fly GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP und geben Sie die Adresse ein, die Stream My Drone anzeigt. Die Vorschau erscheint in der App.
  2. Live Producer öffnenWählen Sie auf facebook.com Live-Video, legen Sie fest, wo gepostet wird (Ihr Profil, eine Seite oder eine Gruppe), und wählen Sie Streaming-Software.
  3. Server-URL und Schlüssel kopierenKopieren Sie die Server-URL (rtmps://live-api-s.facebook.com:443/rtmp/) und den Stream-Schlüssel in ein Facebook-Ziel in Stream My Drone.
  4. LIVE STARTEN drückenWählen Sie vorher die Ausrichtung: Querformat 16:9 passt für Zuschauer am Computer, Hochformat 9:16 für den Feed auf dem Handy. Live Producer zeigt die Vorschau nach wenigen Sekunden.
  5. Auf Facebook Live gehen drückenGeben Sie in Live Producer Titel und Beschreibung ein und drücken Sie Live gehen. Zum Beenden beenden Sie das Video dort und drücken in der App Stream beenden.

Einen dauerhaften Stream-Schlüssel nutzen

Standardmäßig erstellt Facebook für jede Sitzung einen neuen Stream-Schlüssel, den Sie dann jedes Mal in der App aktualisieren müssten. Live Producer bietet die Option, einen dauerhaften Stream-Schlüssel zu verwenden. Schalten Sie sie ein, speichern Sie den Schlüssel einmal in Stream My Drone, und er funktioniert auch für künftige Übertragungen an dieselbe Stelle.

Behandeln Sie einen dauerhaften Schlüssel wie ein Passwort: Wer ihn hat, kann auf Ihrer Seite senden. Stream My Drone bewahrt ihn im Anmeldedaten-Tresor des Systems auf und schreibt ihn nie in eine Datei oder ein Log.

Bildrate30 fps
VideoH.264, 6 Mbit/s CBR, Keyframe alle 2 Sekunden

Häufige Probleme

  • Verbindung fehlgeschlagen: Der Sitzungsschlüssel ist abgelaufen. Kopieren Sie einen neuen aus Live Producer oder wechseln Sie zu einem dauerhaften Schlüssel.
  • Die Adresse beginnt mit rtmp://: Facebook akzeptiert kein unverschlüsseltes RTMP; verwenden Sie die rtmps://-Adresse aus Live Producer.
  • Live Producer empfängt den Stream, aber niemand sieht ihn: Sie müssen in Live Producer noch Live gehen drücken.

Fragen

Kann ich mit einer DJI-Drohne auf Facebook live gehen?

Ja. DJI Fly sendet RTMP an Stream My Drone auf Ihrem Computer, und die App leitet es mit dem Schlüssel aus Live Producer per RTMPS an Facebook weiter.

Kann ich auf eine Facebook-Seite oder in eine Gruppe streamen?

Ja. Legen Sie in Live Producer fest, wo gepostet wird, bevor Sie den Schlüssel kopieren; der Schlüssel gehört zu diesem Ziel.

Warum funktioniert mein Facebook-Stream-Schlüssel nicht mehr?

Facebook vergibt einen Schlüssel pro Sitzung. Schalten Sie in Live Producer den dauerhaften Stream-Schlüssel ein, wenn Sie regelmäßig an dieselbe Stelle streamen.

Kann ich gleichzeitig auf Facebook und Instagram streamen?

Ja, als zwei Ziele in Stream My Drone. Beide bekommen dasselbe Bild, wählen Sie also die Ausrichtung, die zu Ihrem Hauptpublikum passt.

Ist es kostenlos?

Ja. Stream My Drone ist kostenlos und quelloffen und steht in keiner Verbindung zu DJI oder Meta.

Probieren Sie es mit Ihrer Drohne aus

Stream My Drone ist kostenlos und quelloffen, für macOS und Windows. FFmpeg ist integriert, Sie müssen also nichts weiter installieren.
