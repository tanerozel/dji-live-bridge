Eine DJI-Drohne streamen, ohne NGINX und OBS einzurichten

Von Taner Özel · Aktualisiert 3. Oktober 2026

Wer sucht, wie man eine DJI-Drohne in OBS bekommt, findet fast immer denselben Anfang: einen NGINX-RTMP-Server installieren, seine Konfiguration bearbeiten, die Firewall öffnen, DJI Fly darauf richten und den Stream als Medienquelle in OBS holen. Das funktioniert, ist aber ein kleines Serverprojekt. Stream My Drone vereint RTMP-Server, Vorschau, Kodierung und Plattform-Ausgaben in einer App – und kann das Bild trotzdem an OBS übergeben, wenn Sie es möchten.

Kurz gesagt

  • Das klassische Rezept lautet DJI Fly → NGINX mit RTMP-Modul → OBS-Medienquelle → eine Plattform.
  • Dafür installieren Sie einen Server, bearbeiten nginx.conf, geben Port 1935 frei und bauen eine Szene von Hand.
  • Mehrere Plattformen gleichzeitig brauchen ein OBS-Plugin oder einen Cloud-Dienst; eine Leinwand im Hochformat braucht weitere Einrichtung.
  • Stream My Drone empfängt DJI Fly direkt und streamt im Hoch- oder Querformat an mehrere Plattformen, ohne weitere Installation.
  • Wenn Sie OBS trotzdem nutzen möchten, baut OBS-Szene vorbereiten eine Szene DJI LIVE mit dem Drohnenbild für Sie.

Das übliche Rezept mit NGINX und OBS

  1. RTMP-Server installierenNGINX mit RTMP-Modul (unter Windows oft als fertiges Paket) oder einen anderen RTMP-Server.
  2. Konfiguration bearbeitenFügen Sie in nginx.conf einen rtmp-Block mit einer Anwendung wie live hinzu und starten Sie den Server.
  3. Firewall öffnenErlauben Sie eingehende Verbindungen auf Port 1935 und ermitteln Sie die lokale Adresse des Computers.
  4. DJI Fly darauf richtenTragen Sie unter Live Streaming Platforms → RTMP etwa rtmp://192.168.1.20/live/drone ein.
  5. In OBS holenFügen Sie eine Medienquelle mit derselben Adresse hinzu, passen Sie sie auf der Leinwand an und tragen Sie dann in OBS Stream-URL und Schlüssel Ihrer Plattform ein.

Danach ist jede Änderung Handarbeit: Ein neues Netz bedeutet eine neue Adresse, eine zweite Plattform ein Plugin oder einen Relay-Dienst, und ein Stream im Hochformat eine zweite Leinwand oder ein eigenes Profil.

Die Einrichtung mit einer einzigen App

  1. Stream My Drone installierenLaden Sie die App für macOS oder Windows herunter; FFmpeg und der Medienserver sind enthalten.
  2. Adresse in DJI Fly kopierenDie App zeigt eine Adresse wie rtmp://192.168.1.20:1935/drone. Tragen Sie sie in DJI Fly unter GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP ein.
  3. Plattformen hinzufügenInstagram, TikTok, YouTube, Facebook, Twitch, Kick oder einen beliebigen RTMP-Server, jeweils mit URL und Schlüssel.
  4. LIVE STARTEN drückenDas Bild wird einmal kodiert und an jedes aktivierte Ziel gesendet.

Wenn Sie trotzdem OBS möchten

Für Szenen, Overlays und Übergänge ist OBS unschlagbar. Das ersetzt Stream My Drone nicht – es ersetzt den NGINX-Teil. Aktivieren Sie OBS WebSocket (Werkzeuge → WebSocket-Servereinstellungen), verbinden Sie es im Tab „Erweitert“ der App und drücken Sie OBS-Szene vorbereiten: Die App legt eine Szene namens DJI LIVE an, in der das Drohnenbild bereits passend für eine Leinwand im Quer- oder Hochformat liegt.

Für Anrufe in Zoom, Meet oder Teams über OBS Virtual Camera siehe die Webcam-Anleitung.

Fragen

Brauche ich NGINX, um eine DJI-Drohne in OBS zu streamen?

Nein. Stream My Drone enthält einen eigenen RTMP-Server; mit OBS-Szene vorbereiten bringt die App das Drohnenbild auch ohne NGINX in OBS.

Brauche ich OBS, um eine DJI-Drohne zu streamen?

Nein. Stream My Drone streamt direkt auf Instagram, TikTok, YouTube und andere Plattformen. OBS ist für Szenen und Overlays optional.

Ist die NGINX-Methode schlechter?

Sie funktioniert und ist flexibel, aber Sie pflegen Server, Konfigurationsdatei und OBS-Szene selbst, und Multistreaming oder Hochformat brauchen zusätzliche Schritte.

Was kostet Stream My Drone?

Nichts. Die App ist kostenlos und quelloffen unter der MIT-Lizenz.
