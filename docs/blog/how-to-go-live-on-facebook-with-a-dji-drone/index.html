How to go live on Facebook with a DJI drone

By Taner Özel · Updated October 2, 2026

On facebook.com open Live video → Streaming software (Facebook's Live Producer), copy the server URL and stream key into a Facebook destination in DJI Live Bridge, send the drone's picture from DJI Fly to the app, press START LIVE, then press Go live in Live Producer. Facebook only accepts encrypted RTMPS, which the app handles.

In short

  • The server URL and key come from Live Producer: Live video → Streaming software.
  • Server URL: rtmps://live-api-s.facebook.com:443/rtmp/ — Facebook requires RTMPS.
  • Facebook issues a new key per session unless you turn on a persistent stream key.
  • Facebook needs a keyframe every 2 seconds; DJI Live Bridge always sends that.
  • You can post to your profile, a Page or a group, and stream to other platforms at the same time.

Go live on Facebook, step by step

  1. Connect the droneIn DJI Fly open GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP and enter the address DJI Live Bridge shows. The preview appears in the app.
  2. Open Live ProducerOn facebook.com choose Live video, pick where to post (your profile, a Page or a group) and select Streaming software.
  3. Copy the server URL and keyCopy the Server URL (rtmps://live-api-s.facebook.com:443/rtmp/) and the Stream key into a Facebook destination in DJI Live Bridge.
  4. Press START LIVEChoose the orientation first: Horizontal 16:9 suits viewers on computers, Vertical 9:16 suits the phone feed. Live Producer shows the preview after a few seconds.
  5. Press Go live on FacebookAdd a title and description in Live Producer and press Go live. To finish, end the video there and press End stream in the app.

Use a persistent stream key

By default Facebook creates a new stream key for every session, so you would have to update it in the app each time. Live Producer has an option to use a persistent stream key. Turn it on, save the key once in DJI Live Bridge, and it keeps working for future broadcasts to the same place.

Treat a persistent key like a password: anyone who has it can broadcast to your page. DJI Live Bridge keeps it in the system's credential vault and never writes it to a file or a log.

VideoH.264, 6 Mbps CBR, keyframe every 2 seconds

Common problems

  • Connection failed: the session key expired. Copy a new one from Live Producer, or switch to a persistent key.
  • The address starts with rtmp://: Facebook does not accept unencrypted RTMP; use the rtmps:// address from Live Producer.
  • Live Producer receives the stream but nobody sees it: you still have to press Go live in Live Producer.

Questions

Can I go live on Facebook from a DJI drone?

Yes. DJI Fly sends RTMP to DJI Live Bridge on your computer, and the app forwards it to Facebook over RTMPS with the key from Live Producer.

Can I stream to a Facebook Page or group?

Yes. Choose where to post in Live Producer before you copy the key; the key belongs to that destination.

Why does my Facebook stream key stop working?

Facebook issues a key per session. Turn on the persistent stream key in Live Producer if you stream regularly to the same place.

Can I stream to Facebook and Instagram at the same time?

Yes, as two destinations in DJI Live Bridge. Both receive the same picture, so pick the orientation that suits your main audience.

Is it free?

Yes. DJI Live Bridge is free and open source, and is not affiliated with DJI or Meta.
