How to stream a DJI drone on Twitch

By Taner Özel · Updated October 2, 2026

Copy your primary stream key from the Twitch Creator Dashboard → Settings → Stream, add a Custom RTMP destination in DJI Live Bridge with the server rtmp://live.twitch.tv/app and that key, send the drone's picture from DJI Fly to the app, and press START LIVE. Twitch goes live as soon as it receives the stream.

In short

  • Twitch is added as a Custom RTMP destination: server rtmp://live.twitch.tv/app plus your stream key.
  • The stream key is under Creator Dashboard → Settings → Stream and stays the same until you reset it.
  • Use Horizontal 16:9: Twitch viewers mostly watch in landscape.
  • 6 Mbps at 1080p30 with 2-second keyframes fits Twitch's guidance.
  • Twitch starts the broadcast as soon as the stream arrives — there is no separate Go live button.

Stream to Twitch, step by step

  1. Connect the droneIn DJI Fly open GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP and enter the address DJI Live Bridge shows.
  2. Copy the stream keyOn twitch.tv open Creator Dashboard → Settings → Stream and copy the Primary Stream key.
  3. Add a Custom RTMP destinationIn DJI Live Bridge choose Custom RTMP, name it Twitch, enter rtmp://live.twitch.tv/app as the server URL and paste the key.
  4. Choose Horizontal 16:9Under Picture and sound pick Horizontal 16:9 for a 1920×1080 stream.
  5. Press START LIVEYour channel goes live within a few seconds. Set the title and category in the Creator Dashboard; press End stream in the app to finish.

Twitch settings

SettingValue
Server URLrtmp://live.twitch.tv/app (Twitch picks the nearest server)
Resolution1920×1080, horizontal
Frame rate30 fps
Bitrate6 Mbps CBR
KeyframesEvery 2 seconds

Twitch also lists the stream server for each region in its help pages. If the automatic address gives you a slow connection, enter a nearby regional server instead.

Streaming to Twitch and other platforms at once

DJI Live Bridge can send the same picture to Twitch, YouTube and others at the same time. Twitch's rules on simulcasting have changed over the years and can differ for Affiliates and Partners, so check your current agreement before you stream to several platforms.

Common problems

  • Connection failed: check that the server URL is exactly rtmp://live.twitch.tv/app and the key has no extra spaces.
  • Viewers see buffering: the upload is not steady enough. Close other uploads or use a wired connection for the computer.
  • The key was leaked: reset it in the Creator Dashboard and update it in the app.

Questions

Can I stream a DJI drone on Twitch?

Yes. Send DJI Fly's RTMP stream to DJI Live Bridge and add Twitch as a Custom RTMP destination with rtmp://live.twitch.tv/app and your stream key.

Where do I find my Twitch stream key?

On twitch.tv: Creator Dashboard → Settings → Stream → Primary Stream key.

Should I stream vertical video to Twitch?

Usually not. Twitch is mostly watched in landscape, so choose Horizontal 16:9.

Does the Twitch key change?

No, only when you reset it, so you set it up once.

Do I need OBS for Twitch?

No. DJI Live Bridge sends the stream directly. OBS is optional if you want scenes or overlays.
