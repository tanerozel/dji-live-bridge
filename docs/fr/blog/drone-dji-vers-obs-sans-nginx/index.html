Diffuser un drone DJI sans configurer NGINX ni OBS

Par Taner Özel · Mis à jour 3 octobre 2026

Cherchez comment faire entrer un drone DJI dans OBS et la plupart des guides commencent de la même façon : installer un serveur RTMP NGINX, modifier sa configuration, ouvrir le pare-feu, diriger DJI Fly vers lui puis récupérer le flux dans OBS comme source média. Ça marche, mais c'est un petit projet de serveur. Stream My Drone réunit le serveur RTMP, l'aperçu, l'encodage et les sorties vers les plateformes dans une seule application, et peut toujours transmettre l'image à OBS quand vous le souhaitez.

En bref

  • La recette classique : DJI Fly → NGINX avec le module RTMP → source média OBS → une seule plateforme.
  • Il faut installer un serveur, modifier nginx.conf, autoriser le port 1935 et construire une scène à la main.
  • Diffuser sur plusieurs plateformes à la fois demande un plugin OBS ou un service cloud ; un canevas vertical demande encore plus de configuration.
  • Stream My Drone reçoit DJI Fly directement et diffuse sur plusieurs plateformes, en vertical ou en horizontal, sans rien d'autre à installer.
  • Si vous voulez quand même OBS, Préparer la scène OBS crée pour vous une scène DJI LIVE avec le flux du drone.

La recette habituelle NGINX + OBS

  1. Installer un serveur RTMPNGINX avec le module RTMP (sous Windows, souvent un paquet précompilé), ou un autre serveur RTMP.
  2. Modifier la configurationAjouter à nginx.conf un bloc rtmp avec une application comme live, puis démarrer le serveur.
  3. Ouvrir le pare-feuAutoriser les connexions entrantes sur le port 1935 et trouver l'adresse locale de l'ordinateur.
  4. Diriger DJI Fly vers le serveurSaisir quelque chose comme rtmp://192.168.1.20/live/drone sous Live Streaming Platforms → RTMP.
  5. Récupérer le flux dans OBSAjouter une source média avec la même adresse, la dimensionner sur le canevas, puis régler dans OBS l'URL et la clé de stream de votre plateforme.

Ensuite, chaque changement est manuel : un nouveau réseau signifie une nouvelle adresse, une deuxième plateforme signifie un plugin ou un service de relais, et un flux vertical signifie un second canevas ou un profil séparé.

La configuration en une seule application

  1. Installez Stream My DroneTéléchargez-le pour macOS ou Windows ; FFmpeg et le serveur média sont inclus.
  2. Copiez l'adresse dans DJI FlyL'application affiche une adresse du type rtmp://192.168.1.20:1935/drone. Saisissez-la dans DJI Fly sous GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP.
  3. Ajoutez vos plateformesInstagram, TikTok, YouTube, Facebook, Twitch, Kick ou n'importe quel serveur RTMP, chacun avec son URL et sa clé.
  4. Appuyez sur DÉMARRER LE DIRECTL'image est encodée une seule fois et envoyée à chaque destination activée.

Quand vous voulez quand même OBS

OBS est imbattable pour les scènes, les incrustations et les transitions. Stream My Drone ne remplace pas cela ; il remplace la partie NGINX. Activez le WebSocket d'OBS (Outils → Paramètres du serveur WebSocket), connectez-le dans l'onglet Avancé de l'application et appuyez sur Préparer la scène OBS : l'application crée une scène nommée DJI LIVE contenant déjà le flux du drone, ajusté à un canevas horizontal ou vertical.

Pour les appels dans Zoom, Meet ou Teams via OBS Virtual Camera, consultez le guide webcam.

Questions

Faut-il NGINX pour diffuser un drone DJI dans OBS ?

Non. Stream My Drone contient son propre serveur RTMP ; avec Préparer la scène OBS, il place aussi le flux du drone dans OBS sans NGINX.

Faut-il OBS pour diffuser un drone DJI ?

Non. Stream My Drone diffuse directement sur Instagram, TikTok, YouTube et d'autres plateformes. OBS est facultatif, pour les scènes et les incrustations.

La méthode NGINX est-elle moins bonne ?

Elle fonctionne et elle est souple, mais vous entretenez vous-même un serveur, un fichier de configuration et une scène OBS, et le multistreaming ou la vidéo verticale demandent des étapes supplémentaires.

Combien coûte Stream My Drone ?

Rien. Il est gratuit et open source sous licence MIT.
