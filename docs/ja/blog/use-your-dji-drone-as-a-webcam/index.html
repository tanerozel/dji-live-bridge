DJI ドローンをパソコンの Web カメラにする

著者 Taner Özel · 更新日 2026年10月21日

Stream My Drone は再配信だけのアプリではありません。仮想カメラを使うと、DJI Fly から届くライブ映像が Stream My Drone Camera という普通のカメラとしてパソコンに渡されます。TikTok LIVE Studio、OBS、Zoom、Google Meet、Microsoft Teams など、カメラを選べるアプリならどれでもドローンの視点を映せます。ストリームキーも配信用アカウントも要りません。

要点

  • Stream My Drone は、ドローンのライブ映像を映す Stream My Drone Camera というカメラをパソコンに追加します。
  • カメラを選べるアプリならどれでも使えます：TikTok LIVE Studio、OBS、Zoom、Google Meet、Microsoft Teams、ブラウザ上の配信スタジオなど。
  • ストリームキーもプラットフォームのアカウントも不要です。ドローンがそのままカメラになります。
  • カメラは縦型の 1080×1920、30 fps で、映像だけを運びます。マイクはカメラを使うアプリの側で選びます。
  • 横長のビデオ通話では、横 16:9 のレイアウトで OBS を経由し、OBS 仮想カメラを使ってください。

仮想カメラでできること

ふつう、ドローンのライブ映像は配信プラットフォームへ送られます。仮想カメラは別の道を通ります。DJI Fly がパソコンの Stream My Drone へ RTMP で映像を送り、アプリがそれをカメラとして OS に渡すのです。ほかのアプリから見ると、ドローンはパソコンにつないだ Web カメラと同じです。

そのため、相手のアプリにはストリームキーも配信用アカウントも RTMP 対応も必要ありません。カメラのメニューさえあれば、そこにドローンが並びます。

  • 名前：Stream My Drone Camera。
  • 映像：縦型の 1080×1920、30 fps。横長のドローン映像は画面の中央に置かれ、上下は黒になります。切り抜きはしません。
  • 音声：意図的になしにしています。マイクはカメラを使うアプリで選ぶので、音が二重に聞こえることはありません。
  • 対応 OS：macOS 13 以降（アプリをアプリケーションフォルダに入れる必要があります）と Windows 10/11。

活用アイデア

いくつかの例を挙げます。Web カメラを受け付けるものなら、何でもドローンからの景色を映せます。

  • ストリームキーなしで TikTok ライブ。TikTok LIVE Studio でこのカメラを選び、そこから配信します。詳しい手順は TikTok のガイドにあります。
  • OBS で番組を作る。カメラを映像ソースとして追加し、空撮映像の上にテキスト、ロゴ、地図、自分の顔を映すカメラなどを重ねて、OBS から配信や録画をします。
  • ビデオ通話で現場を見せる。屋根、工事現場、太陽光発電所、畑などを、あとで写真を送る代わりに、Zoom、Google Meet、Microsoft Teams で顧客やチーム、保険会社にライブで見てもらえます。
  • バーチャルツアーを行う。物件、キャンプ場、会場、ルートの上空へ視聴者を案内しながら、話して説明できます。
  • 授業やプレゼンに。地理、農業、測量、あるいはドローンの飛行そのものについての授業、ウェビナー、プレゼンで空からの映像を使えます。
  • ブラウザのスタジオに参加。StreamYard や Restream Studio のようなブラウザ上の配信スタジオでも、たいていほかの Web カメラと同じようにこのカメラを選べるので、マルチカメラの番組でドローンをゲストの 1 人にできます。

カメラにドローンの映像が映るのは、Stream My Drone が開いていて DJI Fly が送信している間だけです。映像が届いていないときは、カメラは黒くなります。

ドローンを Web カメラにする方法

  1. アプリを正しい場所にインストールMac では Stream My Drone をアプリケーションフォルダにドラッグします。macOS がカメラ機能拡張を許可するのはそこからだけです。Windows ではインストーラーがカメラを登録します。
  2. ドローンの映像をパソコンへ送るDJI Fly で GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP を開き、アプリの「配信」タブに表示されたアドレスを貼り付けます。送信機とパソコンは同じ Wi-Fi かテザリングにつなぐ必要があります。詳しくは DJI Fly の RTMP ガイドをご覧ください。
  3. カメラを一度だけ有効にするTikTok LIVE Studio タブで仮想カメラを有効にする — 初回のみを押します。macOS が一度だけ、システム設定 → 一般 → ログイン項目と機能拡張 → カメラ機能拡張 で承認を求めます。
  4. カメラを開始するカードに開始できますと表示されたら、仮想カメラを開始を押します。
  5. アプリでカメラを選ぶTikTok LIVE Studio、OBS、Zoom、Meet、Teams でカメラのメニューを開き、Stream My Drone Camera を選びます。マイクもそこで選んでください。

近くにドローンがない？ 「配信」タブの動画ファイルで試すを使うと、録画したクリップが同じ経路で送られるので、飛行前にアプリ側でカメラを設定しておけます。

横長のビデオ通話は OBS 経由で

内蔵カメラが縦型なのは、TikTok LIVE Studio やスマホ中心のプラットフォームが縦型だからです。Zoom、Meet、Teams は横長のカメラを前提に作られているので、アプリやレイアウトによっては縦長の画面の左右に広い帯が入ったり切り抜かれたりして、ドローンの映像が小さくなります。横長の通話には、任意の OBS 連携を使ってください。OBS に 1920×1080 のキャンバスでドローンの映像全体を渡します。

  1. OBS WebSocket をオンにするOBS でツール → WebSocket サーバー設定を開き、サーバーを有効にします（標準のポートは 4455）。
  2. Stream My Drone を OBS に接続詳細設定タブの任意の OBS 連携で、ホスト、ポート、パスワードを入力し、接続先を保存を押します。
  3. 横型のレイアウトを選ぶ「配信」タブの映像と音声で、向きを横 16:9 にします。
  4. シーンを準備するドローンの映像が届いている状態で OBS シーンを準備を押します。アプリが DJI LIVE というシーンを作り、OBS のキャンバスを 1920×1080 にして、ドローンの映像をそこに収めます。
  5. OBS 仮想カメラを開始同じカードの OBS 仮想カメラの横にある仮想カメラを開始を押し、Zoom、Meet、Teams で OBS Virtual Camera を選びます。

きれいな映像にするコツ

  • マイクは 1 つだけ選ぶ。カメラを使うアプリの側で選びます。ドローンのカメラには音声がないので、ミュートするものはありません。
  • 少しの遅延は想定しておく。映像はドローンから送信機へ、Wi-Fi でパソコンへ、そしてカメラへと渡るので、実際より少し遅れます。場所を見せるには問題ありませんが、正確なタイミングが必要な用途には向きません。
  • 安定したネットワークを使う。送信機とパソコンの間の接続が弱いと、映像がカクつきます。遠くのルーターより、パソコンのすぐそばのスマホのテザリングのほうが良いことがよくあります。
  • 720p は普通です。送信機はよく 720p で送ってきます。カメラはそれを画面に合わせて拡大しますが、ネイティブの 1080p であるかのように見せかけることはしません。
  • アプリは開いたままに。Stream My Drone を終了するとカメラも止まります。

カメラが表示されないとき

  • カメラの一覧にない：先に仮想カメラを開始し、それを使うアプリを終了して開き直します。多くのアプリは起動時にしかカメラの一覧を読み込みません。
  • macOS が承認を求めてこなかった：Stream My Drone がアプリケーションフォルダから起動しているか確認し、システム設定 → 一般 → ログイン項目と機能拡張 → カメラ機能拡張 を見てください。
  • アップデート後に止まった：アプリを置き換えると、macOS は古いカメラを無効にします。仮想カメラを開始をもう一度押すと、アプリが自分で有効化を求めます。macOS に求められたら、Mac を再起動してください。
  • 映像が黒い：ドローンの映像が届いていません。「配信」タブのプレビューと、DJI Fly の RTMP アドレスを確認します。
  • ブラウザに表示されない：そのサイトにカメラへのアクセスを許可し、ページを再読み込みします。
  • Windows：内蔵カメラは TikTok LIVE Studio、OBS、Zoom でテスト済みです。映像ソースとして「Stream My Drone Camera」を選んでください。

よくある質問

DJI ドローンを Web カメラとして使えますか？

はい。Stream My Drone を起動し、DJI Fly からそこへ RTMP を送っていれば、カメラを選べるどのアプリでも、ドローンは Stream My Drone Camera という名前のカメラとして表示されます。

Zoom、Google Meet、Microsoft Teams で使えますか？

ほかの Web カメラと同じように選べます。内蔵カメラは縦型なので、横長の通話では OBS 経由のほうがきれいに見えます。横 16:9 のレイアウトで OBS シーンを準備し、通話アプリで OBS Virtual Camera を選んでください。

ストリームキーや配信用アカウントは必要ですか？

いいえ。仮想カメラはパソコンの中だけで動き、プラットフォームには何も送りません。ストリームキーが必要なのは、Stream My Drone 自体が RTMP で配信するときだけです。

仮想カメラに音声は入りますか？

いいえ、映像だけです。マイクはカメラを使うアプリの側で選んでください。

どのドローンで使えますか？

DJI Fly の Live Streaming Platforms に RTMP がある DJI ドローンなら、どれでも使えます。アプリはドローンと直接やり取りせず、RTMP の配信を受け取るだけです。

無料ですか？

はい。Stream My Drone は MIT ライセンスの無料オープンソースで、DJI、Zoom、Google、Microsoft とは提携していません。

お手持ちのドローンで試す

Stream My Drone は macOS と Windows 向けの無料・オープンソースアプリです。FFmpeg を内蔵しているので、ほかに入れるものはありません。

DJI ドローンの映像で動物をリアルタイムに見つけて数える

DJI Fly の RTMP ライブ配信：設定のすべて

DJI Fly で RTMP ライブ配信を設定する方法。設定の場所、入力するアドレス、送信機とパソコンのネットワーク接続、うまくいかないときの対処法を解説します。

DJI Fly で Instagram にライブ配信できない理由（と解決策）

DJI Fly には Instagram の項目がなく、その RTMP クライアントは Instagram が求める暗号化された RTMPS に対応していません。その理由と、それでも DJI ドローンで Instagram ライブを行う方法を解説します。

DJI Neo でライブ配信する方法

DJI Neo でライブ配信する方法。配信できる操縦モード（スマホ、RC-N3、ゴーグル）、DJI Fly の RTMP 設定、Stream My Drone で Instagram・TikTok・YouTube に配信する手順を解説します。

DJI Avata 2 でライブ配信する方法

DJI Avata 2 の FPV 映像をライブ配信する方法。Goggles 3 の映像をスマホの DJI Fly に共有し、RTMP で送って、Instagram・TikTok・YouTube でライブ配信します。

DJI Osmo カメラで Instagram や TikTok などにライブ配信する

DJI Mimo は Osmo Action、Osmo Pocket、Osmo 360 の映像を RTMP で配信できます。それを Stream My Drone に送れば、Instagram、TikTok、YouTube に同時にライブ配信できます。

Osmo Pocket 3 で Instagram と TikTok にライブ配信する方法

DJI Osmo Pocket 3 の映像を DJI Mimo から RTMP で送り、Stream My Drone で Instagram、TikTok、YouTube に同時ライブ配信する方法と、ワイヤレス Web カメラとして使う方法を解説します。

Osmo Action カメラで Instagram と TikTok にライブ配信する方法

DJI Osmo Action 6、5 Pro、4、3 の映像を DJI Mimo から RTMP で送り、Stream My Drone で Instagram、TikTok、YouTube、Twitch に同時ライブ配信する方法と設定を解説します。

DJI ドローンで TikTok LIVE を配信する方法

DJI Fly から DJI ドローンの映像を TikTok でライブ配信する方法。TikTok のストリームキーを使う方法と、キーなしで TikTok LIVE Studio と仮想カメラを使う方法、設定と対処法を解説します。

DJI ドローンで Instagram ライブ配信する方法

DJI ドローンで Instagram ライブを始める方法。instagram.com でストリーム URL とキーを取得し、DJI Fly の RTMP 配信を Stream My Drone 経由で送って、Go live を押します。

DJI ドローンで YouTube ライブ配信する方法

DJI ドローンの映像を YouTube でライブ配信する方法。ライブ配信を有効にし、YouTube Studio でストリームキーをコピーして、DJI Fly の RTMP を Stream My Drone 経由で送ります。設定とコツも紹介します。

DJI ドローンで Facebook ライブ配信する方法

DJI ドローンの映像を Facebook でライブ配信する方法。Live Producer で RTMPS のサーバー URL とストリームキーを取得し、DJI Fly の配信を Stream My Drone 経由で送って配信を始めます。

DJI ドローンを Twitch で配信する方法

DJI ドローンの映像を Twitch でライブ配信する方法。クリエイターダッシュボードでストリームキーをコピーし、Stream My Drone にカスタム RTMP の配信先として Twitch を追加して配信します。

DJI ドローンを Kick で配信する方法

DJI ドローンの映像を Kick でライブ配信する方法。Kick のダッシュボードでストリーム URL とキーをコピーし、Stream My Drone にカスタム RTMP の配信先として追加して配信します。

DJI ドローンの映像を複数のプラットフォームへ同時に配信する

Stream My Drone で、DJI ドローンのライブ映像を TikTok、Instagram、YouTube、Facebook、Twitch、Kick へ同時に配信できます。無料で、パソコンの中だけで動き、再配信サービスも不要です。

Stream My Drone と Restream：ドローンにはどちらを選ぶ？

DJI ドローンの映像を複数のプラットフォームへ配信するなら、Restream のクラウド中継と、自分のパソコンで動く Stream My Drone のどちらが良いか。費用、ウォーターマーク、Instagram、縦型映像、それぞれが向く場面を比べます。

NGINX と OBS を設定せずに DJI ドローンを配信する

DJI Fly の映像を OBS に取り込む定番の方法は、NGINX の RTMP サーバー、設定ファイル、メディアソースの組み合わせです。その手間の中身と、アプリ 1 つで済ませる方法を紹介します。
