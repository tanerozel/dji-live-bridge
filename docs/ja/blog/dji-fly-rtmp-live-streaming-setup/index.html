DJI Fly の RTMP ライブ配信：設定のすべて

著者 Taner Özel · 更新日 2026年10月2日

DJI Fly は、ドローンのライブ映像を任意の RTMP アドレスへ送れます：GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP。送り先を同じネットワーク上で Stream My Drone を動かしているパソコンにすれば、そこから映像を TikTok、Instagram、YouTube、Facebook、Twitch、Kick へ、あるいは複数へ同時に届けられます。

要点

  • RTMP の項目は、DJI Fly の GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP にあります。
  • DJI Fly には rtmp://192.168.1.20:1935/drone のようなアドレスが必要です。お使いのパソコンに合ったアドレスは、Stream My Drone が QR コード付きで表示します。
  • 送信機とパソコンは、同じ Wi-Fi か同じスマホのテザリングにつなぐ必要があります。
  • 送信機が送るのはたいてい 720p の H.264 と AAC 音声です。アプリがそれを 1080p のきれいな縦型または横型の配信に変換します。
  • ゲスト用 Wi-Fi はデバイス同士の通信を遮断することが多いので、通常のネットワークかテザリングを使ってください。

DJI Fly の RTMP 配信のしくみ

RTMP は、ライブ配信プラットフォームが映像を受け取るのに使うプロトコルです。DJI Fly には RTMP クライアントが入っていて、送信機がドローンから受け取った映像を、入力したアドレスへ送り出します。ただ、プラットフォームは向き、キーフレーム、ビットレートなど配信の形式に細かく、配信のたびに別のアドレスを発行するところも多いため、プラットフォームのアドレスを DJI Fly に直接入力してもうまくいくことはあまりありません。

そこで間に入るのが Stream My Drone です。Mac や PC の上で小さな RTMP サーバーを動かし、DJI Fly の配信をそこで受け取ってプレビューを表示し、各プラットフォームが求める形式に再エンコードします。すべてがお使いのパソコンの中で完結し、映像が他人のサーバーを通ることはありません。

DJI Fly で RTMP を設定する

  1. 両方のデバイスを同じネットワークにDJI の送信機とパソコンを同じ Wi-Fi に接続するか、スマホのテザリングをオンにして両方をそこにつなぎます。
  2. Stream My Drone を開くドローンを接続の手順に、rtmp://192.168.1.20:1935/drone のようなアドレスと QR コードが表示されます。数字の部分は、そのネットワークでのパソコンのアドレスです。
  3. DJI Fly で RTMP の画面を開くGO FLY をタップし、•••（3 つの点）、続いて Transmission → Live Streaming Platforms → RTMP をタップします。
  4. アドレスを入力表示されたとおりにアドレスを入力します。お使いの DJI Fly のバージョンが対応していれば、QR コードを読み取ってもかまいません。
  5. 配信を開始DJI Fly で配信を開始します。数秒で Stream My Drone の最初の手順が緑になり、プレビューが表示されます。

どのネットワークを使うか

接続方法使える？メモ
自宅やオフィスの Wi-Fiはい練習に最適です。プラットフォームへのアップロードには自宅や職場のインターネット回線を使います。
スマホのテザリングはい屋外に最適です。送信機とパソコンの両方をつなぎ、アップロードにはモバイルデータを使います。
ゲスト用 Wi-Fi多くの場合だめゲスト用ネットワークはたいていデバイス同士を分離しているため、DJI Fly がパソコンに届きません。
送信機はモバイルデータ、パソコンは別の場所いいえパソコンのローカルアドレスには、そのネットワークの外からは届きません。

送信機からパソコンへの接続には配信の全データが流れるので、パソコンはルーターやテザリングのホストの近くに置いてください。プラットフォームへのアップロードには、配信先 1 つあたり約 10 Mbps の安定した帯域が必要です。

RTMP に対応しているドローン

対応するかどうかはドローン、送信機、DJI Fly のバージョンによって決まり、Stream My Drone 側では決まりません。DJI Fly の Live Streaming Platforms に RTMP があれば使えます。アプリは普通の RTMP 配信を受け取るだけで、ドローンと直接やり取りすることはありません。DJI はバージョンによってこの項目を追加したり外したりするので、お手元の送信機で確認してください。

DJI RC 2 では、DJI Fly のバージョンによっては、送信機にマイクをつなぐまで配信を開始できません。

トラブルシューティング

  • DJI Fly が接続できないと表示する：両方のデバイスが同じネットワークにあるか、アドレスが :1935/drone まで含めてアプリの表示と一致しているかを確認します。
  • 昨日は動いたのに今日は動かない：パソコンのネットワークアドレスが変わった可能性があります。アプリからアドレスをもう一度コピーしてください。
  • ファイアウォールが許可を求めてくる：プライベートネットワークで Stream My Drone が受信接続を受け付けられるよう許可します。
  • 映像がカクつく：パソコンを Wi-Fi に近づけるか、5 GHz のネットワークに切り替えます。周波数帯を行き来する Wi-Fi は短い途切れの原因になります。
  • プレビューに 720p と表示される：それが送信機から送られてくる解像度です。アプリは実際の入力をそのまま表示し、ネイティブの 1080p であるかのように見せかけることはしません。

よくある質問

DJI Fly の RTMP 設定はどこにありますか？

GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP です。そこに RTMP がなければ、お使いのドローン、送信機、または DJI Fly のバージョンが対応していません。

DJI Fly にはどの RTMP アドレスを入力しますか？

Stream My Drone に表示される rtmp://<パソコンのアドレス>:1935/drone という形式のアドレスです。パソコンが別のネットワークにつながると変わります。

DJI Fly から YouTube や Facebook に直接配信できますか？

DJI Fly は任意のアドレスへ RTMP を送れますが、プラットフォームは特定の設定を求め、配信のたびに新しいキーが必要なところもあります。先に Stream My Drone へ送れば、プレビュー、正しい形式、複数の配信先への同時配信が手に入り、各プラットフォームの癖にも自動で対応できます。

インターネット接続は必要ですか？

DJI Fly からパソコンへの接続はローカルです。インターネットを使うのは、パソコンからプラットフォームへの配信だけです。

映像が第三者のサーバーに送られますか？

いいえ。Stream My Drone はすべてお使いのパソコンの中で動き、配信は自分で追加した配信先にだけ送られます。

DJI Fly で Instagram にライブ配信できない理由（と解決策）

DJI Fly には Instagram の項目がなく、その RTMP クライアントは Instagram が求める暗号化された RTMPS に対応していません。その理由と、それでも DJI ドローンで Instagram ライブを行う方法を解説します。

Osmo Action カメラで Instagram と TikTok にライブ配信する方法

DJI Osmo Action 6、5 Pro、4、3 の映像を DJI Mimo から RTMP で送り、Stream My Drone で Instagram、TikTok、YouTube、Twitch に同時ライブ配信する方法と設定を解説します。

DJI ドローンで TikTok LIVE を配信する方法

DJI Fly から DJI ドローンの映像を TikTok でライブ配信する方法。TikTok のストリームキーを使う方法と、キーなしで TikTok LIVE Studio と仮想カメラを使う方法、設定と対処法を解説します。

DJI ドローンで Instagram ライブ配信する方法

DJI ドローンで Instagram ライブを始める方法。instagram.com でストリーム URL とキーを取得し、DJI Fly の RTMP 配信を Stream My Drone 経由で送って、Go live を押します。

DJI ドローンで YouTube ライブ配信する方法

DJI ドローンの映像を YouTube でライブ配信する方法。ライブ配信を有効にし、YouTube Studio でストリームキーをコピーして、DJI Fly の RTMP を Stream My Drone 経由で送ります。設定とコツも紹介します。

DJI ドローンで Facebook ライブ配信する方法

DJI ドローンの映像を Facebook でライブ配信する方法。Live Producer で RTMPS のサーバー URL とストリームキーを取得し、DJI Fly の配信を Stream My Drone 経由で送って配信を始めます。

DJI ドローンを Twitch で配信する方法

DJI ドローンの映像を Twitch でライブ配信する方法。クリエイターダッシュボードでストリームキーをコピーし、Stream My Drone にカスタム RTMP の配信先として Twitch を追加して配信します。

DJI ドローンを Kick で配信する方法

DJI ドローンの映像を Kick でライブ配信する方法。Kick のダッシュボードでストリーム URL とキーをコピーし、Stream My Drone にカスタム RTMP の配信先として追加して配信します。

DJI ドローンの映像を複数のプラットフォームへ同時に配信する

Stream My Drone で、DJI ドローンのライブ映像を TikTok、Instagram、YouTube、Facebook、Twitch、Kick へ同時に配信できます。無料で、パソコンの中だけで動き、再配信サービスも不要です。

Stream My Drone と Restream：ドローンにはどちらを選ぶ？

DJI ドローンの映像を複数のプラットフォームへ配信するなら、Restream のクラウド中継と、自分のパソコンで動く Stream My Drone のどちらが良いか。費用、ウォーターマーク、Instagram、縦型映像、それぞれが向く場面を比べます。

NGINX と OBS を設定せずに DJI ドローンを配信する

DJI Fly の映像を OBS に取り込む定番の方法は、NGINX の RTMP サーバー、設定ファイル、メディアソースの組み合わせです。その手間の中身と、アプリ 1 つで済ませる方法を紹介します。
