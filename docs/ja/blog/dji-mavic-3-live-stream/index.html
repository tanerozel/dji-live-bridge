DJI Mavic 3・Classic・Pro でライブ配信する方法

著者 Taner Özel · 更新日 2026年10月25日

DJI Mavic 3 シリーズは DJI Fly でカメラ映像をライブ送信できますが、使える方法は送信機によって決まります。RC-N1 なら操縦用スマートフォンとパソコンの受信側、RC Pro なら Stream My Drone を入れた別のスマートフォンを使います。画面付きの DJI RC は事情が異なり、DJI はこの送信機でのライブ配信に対応していません。

要点

  • このガイドは一般向けの Mavic 3、Mavic 3 Cine、Mavic 3 Classic、Mavic 3 Pro を対象とし、Mavic 3 Enterprise は扱いません。
  • RC-N1 では DJI Fly をスマートフォンで使います。パソコンで受信する方法なら、受信を別のパソコンで行えます。
  • RC Pro は、別のスマートフォンの Stream My Drone にも、パソコンの Stream My Drone にも RTMP を送れます。
  • DJI RC は操縦には対応していますが、DJI Fly のライブ配信には対応していません。
  • RTMP の映像そのものを確認してください。カメラの録画画質や送信機のライブビューで配信の解像度が決まるわけではありません。

機体と送信機の組み合わせを確認する

一般向けモデルについて、DJI は Mavic 3 Pro サポート FAQ で RC-N1、DJI RC、DJI RC Pro を挙げています。Mavic 3 Classic のサポートページにも 3 機種すべてが載っています。初代 Mavic 3 のサポート情報には RC-N1 と RC Pro が載っており、DJI RC FAQ でも DJI RC が Mavic 3 と Mavic 3 Cine に対応していることが確認できます。これは操縦に関する対応状況であり、どの送信機でも配信できるという意味ではありません。

送信機DJI Fly を動かす場所ライブ配信の方法
DJI RC-N1USB で接続したスマートフォンそのスマートフォンからパソコンの Stream My Drone へ RTMP で送信
DJI RC Pro送信機の内蔵画面Stream My Drone を入れた別のスマートフォン、またはパソコンへ RTMP で送信
DJI RC送信機の内蔵画面DJI Fly のライブ配信には非対応

DJI RC と RC 2、RC Pro と RC Pro 2 を混同しないでください。Mavic 4 Pro の送信機の手順が使えても、Mavic 3 に対応しているとは限りません。Mavic 3 Enterprise や Thermal は別の製品とアプリで運用するため、このガイドの対象外です。

お使いのソフトウェアで RTMP メニューと音声を確認する

配信に対応する送信機で機体とリンクし、DJI Fly のカメラビューを開きます。GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP を探してください。必要なら機体、送信機、DJI Fly を更新し、ライブイベントを計画する前にもう一度メニューを確認します。

DJI のライブ配信ガイドによると、DJI Fly v1.16.0 以降の RC Pro ではマイクの接続が必要で、Fly v1.18.0 以降の RC Pro では RTMP は 720p のみに対応しています。RC-N1 では、接続したスマートフォンで選べる設定が使われます。古い 1080p のチュートリアルをそのまま真似せず、これらの設定を確認してください。

Mavic 3 と RC Pro：スマートフォンで配信を受信する

  1. 別のスマートフォンに Stream My Drone を入れるGoogle Play または App Store からダウンロードします。DJI Fly は RC Pro で開いたままにし、スマートフォンでその映像を受信して転送します。
  2. 送信機と受信側を同じネットワークにつなぐインターネットにつながる Wi-Fi を使います。屋外では、受信用の Android スマートフォンがテザリングを兼ねることもできます。ネットワークを選んでから Stream My Drone を開き、iPhone ではローカルネットワークへのアクセスを求められたら許可します。ネットワークを変えたら、表示されるアドレスをもう一度確認してください。
  3. 受信アドレスを DJI Fly に入力するStream My Drone に表示されるローカル RTMP アドレスを省略せずにコピーします。DJI Fly で GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP を開きます。表示されるラベルはバージョンによって異なり、アドレスとキーを別々に入力する画面と、RTMP URL をまとめて入力する画面があります。ローカルの受信アドレスに YouTube や Instagram のキーを付け足さないでください。メニューの手順は DJI Fly RTMP ガイドを参照してください。
  4. ローカル配信を始めて音声を確認するDJI Fly でライブ配信を始め、Stream My Drone に動く映像が表示されることを確認します。地上テストの間に、送信機で選ばれているマイクを確認し、配信先で音声を聞いてみてください。映像は届いても音声が使えない問題は、離陸前のほうが原因を突き止めやすくなります。
  5. 配信先を追加して公開するアカウント連携が使える配信先ならアカウントを接続し、そうでなければ最新のサーバー URL とストリームキーを Stream My Drone に入力します。転送を始めて配信先のダッシュボードを開きます。別途「ライブ開始」の操作があれば済ませ、実際の視聴ページで見られることを確認してください。

受信用のスマートフォンは送信機とは別の端末です。スマートフォンでの転送では届いた映像がそのまま送られ、プレビューの切り抜きやぼかし背景で新しい縦型の配信が作られるわけではありません。iPhone では設定中はアプリを開いたままにしてください。バックグラウンドで受信を続けられるかはピクチャ・イン・ピクチャに左右されます。

Mavic 3 と RC-N1：別のパソコンで受信する

RC-N1 では、送信機に USB で接続したスマートフォンで DJI Fly を開いたままにします。RC Pro からもこのパソコンの受信側に送れます。Mac または Windows PC に Stream My Drone を入れます。パソコンはローカルネットワーク経由で DJI Fly の RTMP 映像を受信します。この方法では HDMI キャプチャも、送信機からの USB ウェブカメラ接続も使いません。

  1. パソコンのローカル RTMP アドレスをコピーするパソコンと DJI Fly を動かす端末を同じネットワークにつなぎます。Stream My Drone で「ドローンを接続」の下にあるアドレスをコピーします。rtmp://192.168.1.20:1935/drone は一例にすぎないので、アプリに表示されたアドレスを使ってください。
  2. 映像を送り、受信できたか確かめるそのローカルアドレスを DJI Fly に入力して配信を始めます。ファイアウォールに聞かれたら、プライベートネットワークでの接続の受信をアプリに許可してください。配信先を設定する前に、プレビューで映像が動いていることを確認します。
  3. 出力を選び、配信先への送信を始める横向きか、パソコンでの縦型レイアウトを選び、配信先のサーバー URL とキーを追加します。出力を始め、配信先が受信していることを確かめて公開の操作を済ませます。複数の配信先を同時に有効にする前に、合計で必要なアップロード速度を確認してください。

配信できるかどうかはプラットフォームがアカウントごとに決めます。どちらのアプリも、ストリームキーを発行したり利用条件を回避したりはできません。対応する配信スタジオアプリをパソコンで使う場合は、Stream My Drone の仮想カメラも使えます。ローカルのプレビューで分かるのは受信できたことで、公開できたことは視聴ページが見られることで確かめます。

視聴者には実際にどの解像度で届くのか

Mavic 3 シリーズの高解像度のカメラ録画や O3+ による送信機の映像は、RTMP エンコーダーの出力とは別のものです。エンコーダーが送らなかった細部を受信側で取り戻すことはできません。機体の録画仕様をライブ配信の画質として約束せず、受信した映像のサイズと配信先での再生画質を確認してください。

これは、レンズの異なる Mavic 3 Pro では特に役立ちます。ライブを始める前に、使う予定のレンズと構図を受信側でテストしてください。カメラや録画の設定を変えても、送り出される映像の確認の代わりにはなりません。縦型の配信先には、パソコン版の Stream My Drone で映像を切り抜くか縦型の出力に収められます。スマートフォンアプリは届いた映像をそのまま転送します。

  • ローカルでの受信とインターネットへのアップロードを分けて考える。送信機はローカルネットワーク経由で受信側に届く必要があり、受信側には配信先の数に見合ったアップロード速度が必要です。
  • 必要なアップロード速度は合計で考える。5 Mbps の出力が 2 つなら、合計で約 10 Mbps のアップロード速度が必要で、オーバーヘッドを除いて 1 時間あたり約 4.5 GB を使います。テスト中は配信先を 1 つにして始めましょう。
  • 映像だけでなく音も確認する。送信機または操縦用スマートフォンで選ばれているマイクを確認し、配信先で音声を聞いてください。機体のカメラ映像に使える音声が含まれているとは限りません。

Mavic 3・Classic・Pro の配信がうまくいかないとき

  • DJI RC に RTMP のメニューがない：その送信機で機体を操縦できても、これは公式に案内されている制限です。Stream My Drone で DJI RC にライブ配信機能を追加することはできません。このガイドの手順には、対応する RC-N1 か RC Pro を使ってください。
  • RC Pro で配信が始まらない：マイクの接続と DJI Fly の案内を確認し、現在の RTMP 設定を確かめます。
  • RC-N1 のスマートフォンの接続が切れる：受信側を調べる前に、DJI Fly に機体との接続が表示されているかを確認し、USB ケーブルを点検してください。
  • 受信側に接続できない：ネットワークを変えたら、現在のローカルアドレスをコピーし直します。端末分離のあるゲスト Wi-Fi は避け、パソコンのファイアウォールを確認してください。操縦用の端末で localhost と入力すると、その端末自身を指します。
  • 映像は届くのに誰も視聴できない：配信先への出力を始め、配信先の最新の認証情報を確認し、配信先での公開手順を済ませます。受信側のプレビューだけでは配信は公開されません。

公式情報と次のステップ

2026年10月25日に確認：機種と送信機の違いは Mavic 3 Pro サポート、Mavic 3 Classic サポート、初代 Mavic 3 サポート、DJI RC FAQ、配信の対応状況と制限は DJI Fly ライブ配信操作ガイドを参照しました。実際に使えるメニューは、お使いの機体と送信機のファームウェアで確認してください。

新しい世代については Mavic 4 Pro ライブ配信ガイドをご覧ください。より小型の画面付き送信機の構成なら Mini 5 Pro を参照してください。複数の配信先で公開するなら、同時配信ガイドへ進みましょう。

よくある質問

一部のセットに含まれる DJI RC で Mavic 3 Pro のライブ配信はできますか？

DJI RC で Mavic 3 Pro を操縦することはできますが、DJI はこの送信機でのライブ配信に対応していません。このガイドの RTMP 配信には、対応する RC-N1 と操縦用スマートフォン、または対応する RC Pro を使ってください。

このガイドは Mavic 3 Classic や Mavic 3 Cine にも使えますか？

はい。上で説明した一般向けモデルと対応する送信機の組み合わせであれば使えます。別の運用となる Mavic 3 Enterprise や Thermal は対象外です。

パソコンなしで RC Pro の映像をスマートフォンで受信できますか？

DJI Fly を RC Pro で開いたまま、同じローカルネットワーク上の別のスマートフォンで Stream My Drone を使います。アプリの受信アドレスを DJI Fly に入力し、配信先は Stream My Drone で設定してください。

RC-N1 の操縦用スマートフォンを受信側にもできますか？

そのスマートフォンはすでに飛行のために DJI Fly を動かしています。このガイドでは操縦アプリを開いたままにできるよう、Stream My Drone を別のパソコンで使います。1 台のスマートフォンで飛行と中継の両方をこなせることは前提にしていません。

古い RC Pro のガイドではもっと高い解像度が書かれているのはなぜですか？

DJI Fly でできることはソフトウェアのバージョンによって変わります。現在の送信機の設定と公式のライブ配信ガイドを確認し、録画仕様や古いチュートリアルに頼らず、受信した映像を確かめてください。

配信先のストリームキーは DJI Fly に入力しますか？

この中継の構成では、DJI Fly にはスマートフォン版またはパソコン版の Stream My Drone に表示されるローカルアドレスを入力します。配信先のサーバー URL とストリームキーは、受信アプリの配信先設定に入力してください。

DJI ドローンの映像を Facebook でライブ配信する方法。Live Producer で RTMPS のサーバー URL とストリームキーを取得し、DJI Fly の配信を Stream My Drone 経由で送って配信を始めます。

DJI ドローンを Twitch で配信する方法

DJI ドローンの映像を Twitch でライブ配信する方法。クリエイターダッシュボードでストリームキーをコピーし、Stream My Drone にカスタム RTMP の配信先として Twitch を追加して配信します。

DJI ドローンを Kick で配信する方法

DJI ドローンの映像を Kick でライブ配信する方法。Kick のダッシュボードでストリーム URL とキーをコピーし、Stream My Drone にカスタム RTMP の配信先として追加して配信します。

DJI ドローンの映像を複数のプラットフォームへ同時に配信する

Stream My Drone で、DJI ドローンのライブ映像を TikTok、Instagram、YouTube、Facebook、Twitch、Kick へ同時に配信できます。無料で、パソコンの中だけで動き、再配信サービスも不要です。

Stream My Drone と Restream：ドローンにはどちらを選ぶ？

DJI ドローンの映像を複数のプラットフォームへ配信するなら、Restream のクラウド中継と、自分のパソコンで動く Stream My Drone のどちらが良いか。費用、ウォーターマーク、Instagram、縦型映像、それぞれが向く場面を比べます。

NGINX と OBS を設定せずに DJI ドローンを配信する

DJI Fly の映像を OBS に取り込む定番の方法は、NGINX の RTMP サーバー、設定ファイル、メディアソースの組み合わせです。その手間の中身と、アプリ 1 つで済ませる方法を紹介します。
