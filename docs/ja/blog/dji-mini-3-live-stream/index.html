DJI Mini 3 でライブ配信する方法

著者 Taner Özel · 更新日 2026年10月25日

DJI Mini 3 には、RC-N1 とスマートフォンの DJI Fly を使う公式のライブ配信機能があります。その RTMP 映像を別のパソコンの Stream My Drone に送り、そこから配信先へ転送します。お使いの Mini 3 に画面付きの DJI RC が付属している場合は、まず送信機の制限を確認してください。DJI はこの送信機でのライブ配信に対応していません。

要点

  • ここで説明する対応済みの方法は、Mini 3 → RC-N1 と DJI Fly のスマートフォン → 別のパソコン、という流れです。
  • DJI の Mini 3 ガイドには、初代 DJI RC で使えるライブ配信の方法はありません。DJI RC 2 とは別の製品です。
  • Mini 3 の送信機のライブビューは仕様上 720p/30fps です。4K 録画の機能はそれとは別の出力です。
  • 操縦用の USB 接続と、ネットワーク経由の RTMP 接続は役割が異なります。
  • 最初の確認はパソコンのプレビュー、公開の確認は配信先の視聴ページで行います。

Mini 3 と RC-N1・DJI RC：ライブ配信できるのはどちら？

DJI の Mini 3 FAQ では、対応送信機として RC-N1 と DJI RC が挙げられています。ただし、配信機能は同じではありません。公式入門ガイドでは、RC-N1 とモバイル端末でのライブ配信に対応し、DJI RC は対象外とされています。

お使いの送信機操縦画面ライブ配信の準備
DJI RC-N1USB で接続したスマートフォンの DJI Fly以下の、RTMP でパソコンへ送る手順を使う
DJI RCDJI Fly が動く内蔵画面公式に案内されている DJI Fly のライブ配信の方法は使えない

スマートフォンのテザリングを使っても、DJI RC にライブ配信機能は追加されません。Mini 4 Pro や Mini 5 Pro のガイドにある RC 2 の手順には従わないでください。送信機を購入・変更する前に、DJI の最新の対応機種情報とお使いの構成を確認しましょう。

3 つの接続を理解する

接続役割設定するもの
Mini 3 ↔ RC-N1操縦と機体のカメラ映像通常の機体と送信機のペアリング
RC-N1 ↔ スマートフォン（USB）DJI Fly の操縦画面とライブ配信の操作対応するスマートフォンと送信機のケーブル
スマートフォン → パソコン（ローカルネットワーク経由）DJI Fly の RTMP 映像を Stream My Drone に送るパソコンのアプリに表示される受信アドレス

パソコンは、インターネット接続を使って選んだ配信先に映像を送ります。パソコンと操縦用スマートフォンを同じローカルネットワークに接続してください。インターネットにつながっていても、そのネットワークが端末どうしの通信を遮断していると使えません。DJI Fly は操縦用スマートフォンで開いたままにし、受信側はパソコンで操作します。

DJI の Mini 3 FAQ にあるとおり、QuickTransfer は撮影したファイルを移すための機能です。このライブ配信で使う RTMP 接続ではありません。パソコンへの USB ケーブル接続も、以下の受信アドレスの代わりにはなりません。

Mini 3 の RTMP 配信を設定して公開する

  1. アプリとネットワークを準備するMini 3、RC-N1、操縦用スマートフォンをいつもどおり接続します。Mac または Windows パソコンに Stream My Drone を入れます。パソコンと操縦用スマートフォンを、インターネットにつながる共有のローカルネットワークに接続します。テザリングを使う場合は飛行前にテストしてください。
  2. パソコンの RTMP アドレスを省略せずにコピーするStream My Drone を開き、「ドローンを接続」の下にあるアドレスをコピーします。rtmp://192.168.1.20:1935/drone は形式の例にすぎません。アプリに表示されている現在のアドレスを、パスまで含めて使ってください。
  3. DJI Fly の RTMP 出力を始めるスマートフォンのカメラビューで ••• → Transmission → Enable Livestreaming または Live Streaming Platforms を開き、RTMP を選びます。受信アドレスを貼り付けて開始します。メニューの表記はバージョンによって異なることがあります。共通の手順は DJI Fly RTMP ガイドをご覧ください。
  4. パソコンで映像を確認する受信側でプライベートネットワークのファイアウォールの確認が表示されたら許可し、Stream My Drone に動く映像が表示されることを確認します。映像が届かない場合は、配信先を設定する前にこのローカル接続を直してください。操縦用スマートフォンは DJI Fly の画面のままにしておきます。
  5. 配信先を追加して配信を確認するパソコンでの出力レイアウトを選び、配信先の最新のサーバー URL とストリームキーを配信先として入力して出力を始めます。配信先のダッシュボードを開き、必要な「ライブ開始」の操作を済ませ、視聴ページで音声も含めて確認します。

YouTube、Instagram、Facebook、TikTok を準備する

プラットフォーム必要なアカウントの権限次に読むガイド
YouTubeライブ配信が有効で、配信枠の準備ができているドローンから YouTube へ
Instagramアカウントで Live Producer と RTMPS の情報が使えるドローンから Instagram へ
FacebookLive Producer の配信と、その最新の URL とキードローンから Facebook へ

公開配信を計画する前に、お使いの配信先のダッシュボードを確認してください。ドローンの映像を受信しても、アカウントの配信条件が満たされるわけではありません。ウェブカメラを受け付けるデスクトップアプリ向けには、仮想カメラのガイドで映像ソースとして使う方法を説明しています。その場合も、配信先の利用権限と Mini 3 からの RTMP 映像は必要です。

Mini 3 ではどの程度の画質が期待できるか

DJI の Mini 3 仕様には、DJI O2 伝送で送信機のライブビューが 720p/30fps であること、そしてそれとは別に 4K のカメラ録画が記載されています。4K のファイルが保存されたからといって、4K で RTMP 配信できる証拠にはなりません。受信側に実際に届く入力を確認し、お使いの DJI Fly のバージョンで選べる設定を使ってください。

  • アップスケールには限界がある。パソコンの出力を大きなサイズにはできますが、低解像度の入力にない細部は再現できません。
  • 縦型の構図を確認する。Mini 3 の回転するカメラと最終的な配信画面は、構成の中の別の部分です。縦型の映像を公開する前に、パソコンの実際の出力を確認してください。
  • アップロードに余裕を持たせる。飛行する場所でテストし、配信先 1 つから始めます。5 Mbps ずつ送る配信先が 2 つなら、オーバーヘッドを除いて合計で約 10 Mbps のアップロード速度が必要です。
  • 通信量と電源を見積もる。5 Mbps の出力 1 つで、オーバーヘッドを除いて 1 時間あたり約 2.25 GB を使います。予定している配信の間、操縦用スマートフォンとパソコンの電源を確保してください。

Mini 3 のライブ配信でよくある問題

  • ライブ配信の設定が見つからない：お使いの送信機が初代 DJI RC かどうかを確認してください。公式に案内されている制限なので、受信アプリでは解決できません。RC-N1 なら、DJI Fly の更新と機体との接続を確認します。
  • DJI Fly で接続エラーが出る：現在の受信アドレスを省略せずにコピーし直します。Wi-Fi ネットワーク、端末分離、パソコンのファイアウォールを確認してください。localhost はそれを使う端末自身を指し、ネットワーク上のパソコンを指すわけではありません。
  • プレビューは動くのに公開できない：ローカルの映像は届いています。配信先の URL、現在のキー、アカウントの権限、最後の公開操作を一つずつ確認してください。
  • 屋外で映像が止まる：ローカルの Wi-Fi とインターネットのアップロードの両方を確認します。受信側をネットワークの発信元に近づけ、設定できるならビットレートを下げた出力 1 つでテストしてください。
  • 映像はあるのに音が出ない：受信側と配信先の音声設定を確認し、視聴用の端末で聞いてみてください。仮想カメラを使う場合は、受け取る側の配信アプリで音声を別に設定します。

よくある質問

DJI Mini 3 はライブ配信に対応していますか？

DJI は、RC-N1 と DJI Fly を動かすモバイル端末でのライブ配信を案内しています。このガイドでは、その映像を別のパソコンの Stream My Drone に送ります。

DJI RC 付きの Mini 3 セットでもこの RTMP の手順を使えますか？

いいえ。DJI の Mini 3 入門ガイドでは、初代 DJI RC ではライブ配信を利用できないとされています。新しい DJI RC 2 とは別の製品です。

Mini 3 で 4K のカメラ映像を配信できますか？

ライブ映像が保存される録画と同じだと考えないでください。DJI は Mini 3 の送信機のライブビューを 720p/30fps としています。受信側で実際の RTMP 入力を確認してください。

RTMP の代わりに QuickTransfer を使えますか？

いいえ。QuickTransfer は撮影したファイルをスマートフォンへ移す機能です。この構成では、ローカルネットワーク経由で DJI Fly のライブ配信出力を使います。

操縦用スマートフォンを受信側にもできますか？

このガイドでは、DJI Fly を RC-N1 のスマートフォンに置いたまま、別のパソコンで映像を受信します。操縦アプリと中継アプリが 1 台のスマートフォンで安定して共存できることは前提にしていません。

配信先のストリームキーはどこに入力しますか？

Stream My Drone の配信先設定に、配信先のサーバー URL とあわせて入力します。DJI Fly には、代わりにアプリに表示されるパソコンのローカルアドレスをパスまで含めて入力します。

DJI Fly で Instagram にライブ配信できない理由（と解決策）

DJI Fly には Instagram の項目がなく、その RTMP クライアントは Instagram が求める暗号化された RTMPS に対応していません。その理由と、それでも DJI ドローンで Instagram ライブを行う方法を解説します。

DJI ドローンをパソコンの Web カメラにする

DJI ドローンで TikTok LIVE を配信する方法

DJI ドローンで Instagram ライブ配信する方法

DJI ドローンで Instagram ライブを始める方法。instagram.com でストリーム URL とキーを取得し、DJI Fly の RTMP 配信を Stream My Drone 経由で送って、Go live を押します。

DJI ドローンで YouTube ライブ配信する方法

DJI ドローンの映像を YouTube でライブ配信する方法。ライブ配信を有効にし、YouTube Studio でストリームキーをコピーして、DJI Fly の RTMP を Stream My Drone 経由で送ります。設定とコツも紹介します。

DJI ドローンで Facebook ライブ配信する方法

DJI ドローンの映像を Facebook でライブ配信する方法。Live Producer で RTMPS のサーバー URL とストリームキーを取得し、DJI Fly の配信を Stream My Drone 経由で送って配信を始めます。

DJI ドローンを Twitch で配信する方法

DJI ドローンの映像を Twitch でライブ配信する方法。クリエイターダッシュボードでストリームキーをコピーし、Stream My Drone にカスタム RTMP の配信先として Twitch を追加して配信します。

DJI ドローンを Kick で配信する方法

DJI ドローンの映像を Kick でライブ配信する方法。Kick のダッシュボードでストリーム URL とキーをコピーし、Stream My Drone にカスタム RTMP の配信先として追加して配信します。

DJI ドローンの映像を複数のプラットフォームへ同時に配信する

Stream My Drone で、DJI ドローンのライブ映像を TikTok、Instagram、YouTube、Facebook、Twitch、Kick へ同時に配信できます。無料で、パソコンの中だけで動き、再配信サービスも不要です。

Stream My Drone と Restream：ドローンにはどちらを選ぶ？

DJI ドローンの映像を複数のプラットフォームへ配信するなら、Restream のクラウド中継と、自分のパソコンで動く Stream My Drone のどちらが良いか。費用、ウォーターマーク、Instagram、縦型映像、それぞれが向く場面を比べます。

NGINX と OBS を設定せずに DJI ドローンを配信する

DJI Fly の映像を OBS に取り込む定番の方法は、NGINX の RTMP サーバー、設定ファイル、メディアソースの組み合わせです。その手間の中身と、アプリ 1 つで済ませる方法を紹介します。
