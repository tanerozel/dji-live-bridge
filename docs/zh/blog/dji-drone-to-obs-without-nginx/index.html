不用搭建 NGINX 和 OBS，也能直播 DJI 无人机

作者 Taner Özel · 更新于 2026年10月3日

搜索如何把 DJI 无人机接入 OBS，大多数教程的开头都一样：安装 NGINX RTMP 服务器，修改配置，打开防火墙，让 DJI Fly 指向它，再把推流作为媒体源拉进 OBS。这能用，但相当于一个小型服务器项目。Stream My Drone 把 RTMP 服务器、预览、编码和平台输出都放进一个应用——需要时仍然可以把画面交给 OBS。

要点速览

  • 经典做法是 DJI Fly → 带 RTMP 模块的 NGINX → OBS 媒体源 → 一个平台。
  • 这意味着要安装服务器、修改 nginx.conf、放行 1935 端口，并手动搭建场景。
  • 同时推流到多个平台需要 OBS 插件或云服务；竖屏画布还需要额外设置。
  • Stream My Drone 直接接收 DJI Fly 的推流，并以竖屏或横屏推流到多个平台，无需安装其他软件。
  • 如果你还是想用 OBS，准备 OBS 场景会帮你建好一个带无人机画面的 DJI LIVE 场景。

常见的 NGINX + OBS 做法

  1. 安装 RTMP 服务器带 RTMP 模块的 NGINX（Windows 上通常是预编译的整合包），或其他 RTMP 服务器。
  2. 修改配置在 nginx.conf 中添加一个 rtmp 块，其中包含一个类似 live 的 application，然后启动服务器。
  3. 打开防火墙允许 1935 端口的传入连接，并查到电脑的本地地址。
  4. 让 DJI Fly 指向它在 Live Streaming Platforms → RTMP 下填入类似 rtmp://192.168.1.20/live/drone 的地址。
  5. 拉进 OBS用同一地址添加一个媒体源，在画布上调整大小，然后在 OBS 中填写平台的推流地址和密钥。

此后每次变动都得手动处理：换个网络就要换地址，加第二个平台就需要插件或转推服务，竖屏直播则需要第二个画布或单独的配置文件。

一个应用搞定的设置方法

  1. 安装 Stream My Drone下载 macOS 或 Windows 版；FFmpeg 和媒体服务器都已内置。
  2. 把地址填进 DJI Fly应用会显示类似 rtmp://192.168.1.20:1935/drone 的地址。在 DJI Fly 的 GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP 中填入它。
  3. 添加你的平台Instagram、TikTok、YouTube、Facebook、Twitch、Kick 或任意 RTMP 服务器，各自填写地址和密钥。
  4. 按下“开始直播”画面只编码一次，再发送到每个已启用的推流目标。

如果你还是想用 OBS

在场景、叠加层和转场方面，OBS 无可替代。Stream My Drone 并不取代这些——它取代的是 NGINX 那部分。启用 OBS WebSocket（Tools → WebSocket Server Settings），在应用的“高级”标签页中连接它，然后按准备 OBS 场景：应用会创建一个名为 DJI LIVE 的场景，无人机画面已经放在里面，并按横屏或竖屏画布调整好大小。

想通过 OBS Virtual Camera 在 Zoom、Meet 或 Teams 中通话，请看网络摄像头指南。

常见问题

把 DJI 无人机推流到 OBS 需要 NGINX 吗？

不需要。Stream My Drone 自带 RTMP 服务器；使用“准备 OBS 场景”时，它还能不借助 NGINX 就把无人机画面放进 OBS。

直播 DJI 无人机需要 OBS 吗？

不需要。Stream My Drone 可以直接推流到 Instagram、TikTok、YouTube 和其他平台。OBS 只是做场景和叠加层时的可选工具。

NGINX 方法更差吗？

它能用，也很灵活，但你得自己维护服务器、配置文件和 OBS 场景，而且多平台推流或竖屏视频都需要额外步骤。
