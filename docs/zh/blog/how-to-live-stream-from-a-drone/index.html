无人机怎么直播？（5 步教程，2026）

作者 Taner Özel · 更新于 2026年11月8日

用无人机直播，先在无人机 App 中打开 RTMP（DJI Fly：GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP），再把画面推流到同一 Wi-Fi 下手机或电脑上的接收端，例如 Stream My Drone。接收端会把画面转发到 YouTube、Instagram、TikTok、Facebook、Twitch 或 Kick，也可以同时推到多个平台。

  • 网络短暂中断后，各平台会自动重新连接

要点速览

  • 需要：App 支持 RTMP 直播的无人机（DJI Fly 中的大多数新款大疆机型）、一台接收推流的第二台设备，以及稳定的上传带宽。

5 步实现无人机直播

  1. 确认无人机 App 支持 RTMP在 DJI Fly 中打开 GO FLY → ••• → Transmission → Live Streaming Platforms。如果列表中有 RTMP，说明你的无人机、遥控器和 App 版本都能直播。较老的大疆无人机使用 DJI GO 4，其中也有类似的自定义 RTMP 选项。
  2. 在第二台设备上安装接收端在安卓手机、iPhone、Mac 或 Windows 电脑上安装 Stream My Drone。使用 DJI RC 2 这类带屏遥控器时，任何手机都能接收。使用 RC-N2 或 RC-N3 时，DJI Fly 已经在你的手机上运行，所以要用第二部手机或电脑接收。
  3. 让两台设备连上同一个网络把遥控器（或运行 DJI Fly 的手机）和接收端连到同一个 Wi-Fi，或者打开接收手机的热点。访客 Wi-Fi 通常会阻止设备之间互相访问。
  4. 在 DJI Fly 中填写 RTMP 地址Stream My Drone 会显示类似 rtmp://192.168.1.20:1935/drone 的地址。在 DJI Fly 的 RTMP 页面输入它并点击 Start Livestream，几秒内无人机画面就会出现在 App 中。
  5. 添加平台并开播用推流地址和密钥添加 YouTube、Instagram、TikTok、Facebook、Twitch、Kick 或自定义 RTMP 服务器，打开需要的目标后开始直播。Instagram 和 Facebook 还需要在平台页面上点击“开始直播”。

不同版本 DJI Fly 的菜单名称略有差别。带截图的完整步骤见 DJI Fly RTMP 设置教程。

无人机直播需要准备什么

  • 支持 RTMP 的无人机和遥控器：大多数新款 DJI Fly 机型，例如 Mini 3、Mini 4 Pro、Mini 5 Pro、Air 3、Air 3S、Mavic 3、Mavic 4 Pro、Neo、Flip 和 Avata 2（需 Goggles 3 和手机）。
  • 接收设备：安卓手机（Android 9 及以上）、iPhone、Mac 或 Windows 10/11 电脑。
  • 上传稳定的网络：在家练习用 Wi-Fi，外拍时用 4G 或 5G 手机热点。
  • 可以直播的平台账号：YouTube 需要先为频道开通直播（最多 24 小时），TikTok 只向部分账号提供推流密钥。
  • 使用 DJI RC 2 时：准备 USB-C 麦克风，或使用安卓 App 的虚拟蓝牙麦克风，因为 DJI Fly 1.16+ 没有麦克风就不会开播。
  • 电量：直播比单纯飞行更耗遥控器和手机的电，记得带充电宝。

哪些无人机可以直播？

只要 App 的 Live Streaming Platforms 中有 RTMP 的无人机都可以。接收端从不和无人机直接通信，只接收 DJI Fly 发来的内容。不同机型之间变化的是遥控器，也就决定了 DJI Fly 运行在哪台设备上。

网速和画质

项目建议
每个平台的上传稳定 6–10 Mbps（6 Mbps 视频加余量）
遥控器输出DJI RC 2 为 720p；RC-N2 和 RC-N3 为 1080p 或 720p（安卓 5 或 3 Mbps，iOS 2 或 1 Mbps）
方向TikTok 和 Instagram 用竖屏 9:16；YouTube、Facebook、Twitch 和 Kick 用横屏 16:9
关键帧每 2 秒一个；接收 App 会自动设置
本地网络5 GHz Wi-Fi 或手机热点；避免访客 Wi-Fi 和会切换频段的路由器

直播画质受遥控器输出限制，但录在无人机存储卡上的视频保持原画质。想要更清晰的回放，可以之后再上传录像。

直播时安全飞行

  • 起飞前设置好直播，或交给第二个人负责。飞手的眼睛应该看着无人机，而不是评论区。
  • 遵守所在国家或地区的无人机规定：实名登记、目视范围内飞行、高度限制、不在人群上方飞行。直播中出现的人可能需要同意。
  • 不要在屏幕上露出推流密钥；拿到密钥的人都能在你的频道直播。
  • 留意遥控器和手机电量；热点加直播会很快耗光手机电量。

常见问题排查

  • DJI Fly 连不上：两台设备必须在同一网络，地址必须完全一致，包括 :1935/drone。访客 Wi-Fi 经常会拦截。
  • RC 2 提示 “No built-in mic in current device”：接一个麦克风，或把安卓 App 当作虚拟麦克风；见 RC 2 麦克风问题解决方法。
  • Instagram 或 Facebook 不接受 DJI Fly：它们需要 RTMPS，而 DJI Fly 不支持。原因和解决办法。
  • 画面卡顿或断流：靠近路由器或热点，使用 5 GHz，并避免路由器切换频段。
  • App 里有画面，平台上没有：检查推流密钥，并在 Instagram 或 Facebook 上点击“开始直播”。

常见问题

无人机可以直播吗？

可以。大多数新款大疆无人机都能在 DJI Fly 中通过 RTMP 发送实时画面。可以直接推到一个平台，也可以推到手机或电脑上的接收 App，再由它同时转发到 YouTube、Instagram、TikTok、Facebook 等平台。

不用电脑能用无人机直播吗？

能。使用 DJI RC 2 这类带屏遥控器时，在手机上运行 Stream My Drone，并让遥控器连上这部手机的热点。使用 RC-N2 或 RC-N3 时，DJI Fly 已经占用了你的手机，所以接收端要运行在第二部手机上。

大疆无人机能直接直播到 YouTube 吗？

能。DJI Fly 可以向 YouTube 的推流地址和密钥推送 RTMP。但只有一个目标，也没有预览；加一个接收 App 就有了预览、多平台和自动重连。

为什么 DJI Fly 无法直播到 Instagram？

Instagram 只接受加密的 RTMPS，而且每次直播都会给新密钥，而 DJI Fly 发送的是未加密的 RTMP。把 DJI Fly 的推流发到 Stream My Drone，它会用 RTMPS 转发到 Instagram。

无人机直播需要多少网速？

每个平台大约需要 6–10 Mbps 的稳定上传。信号好的 4G 或 5G 热点通常足够推一到两个平台。

无人机直播是什么分辨率？

取决于遥控器：DJI RC 2 为 720p，RC-N2 或 RC-N3 搭配安卓手机最高 1080p。录在无人机上的视频仍是完整分辨率。

无人机直播免费吗？

DJI Fly 的 RTMP 功能和各平台都是免费的。Stream My Drone 的 Mac 和 Windows 版免费；安卓和 iPhone 版是一次性买断，无需订阅。
