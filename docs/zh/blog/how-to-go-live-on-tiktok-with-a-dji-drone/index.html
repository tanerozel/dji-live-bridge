如何用 DJI 无人机在 TikTok 直播

作者 Taner Özel · 更新于 2026年10月21日

DJI Fly 本身无法推流到 TikTok，但它可以把 RTMP 发送到电脑。Stream My Drone 接收这路推流，并通过两种方式之一送到 TikTok：如果你的账号有 TikTok 服务器地址和推流密钥，就直接推流；或者通过 TikTok LIVE Studio，无人机在其中显示为一个摄像头，不需要推流密钥。

要点速览

  • 你需要一台 DJI Fly 在 Live Streaming Platforms 下提供 RTMP 的 DJI 无人机，以及一台与遥控器连在同一 Wi-Fi 或热点上的 Mac 或 Windows 电脑。
  • 有推流密钥：在 Stream My Drone 中添加 TikTok 推流目标，然后按“开始直播”。
  • 没有推流密钥：在 TikTok LIVE Studio 中选择“Stream My Drone Camera”作为摄像头源，从那里开播。
  • TikTok 需要竖屏视频；应用以 1080×1920、30 fps 发送，空白处用画面的模糊副本填充。
  • 谁能开 LIVE、谁能拿到推流密钥由 TikTok 决定；具体要求取决于你的账号和地区。

准备工作

  • 一套 DJI Fly 在 Live Streaming Platforms 下显示 RTMP 的 DJI 无人机和遥控器。只要你的 DJI Fly 版本有这个选项，无人机就能用——应用从不直接与无人机通信。
  • 一台安装了 Stream My Drone 的 Mac（macOS 13 或更新版本，Apple Silicon 或 Intel）或 Windows 10/11 电脑。
  • 遥控器和电脑连在同一个 Wi-Fi 网络上，或都连在你的手机热点上。
  • 一个可以开 LIVE 的 TikTok 账号。直接推流方式还需要 RTMP 权限（服务器地址和推流密钥）；LIVE Studio 方式需要能使用 TikTok LIVE Studio。

第 1 步：把无人机画面发到电脑

  1. 打开 Stream My Drone“开始直播”标签页会显示类似 rtmp://192.168.1.20:1935/drone 的地址和一个二维码。
  2. 在 DJI Fly 中打开 RTMP 页面GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP。
  3. 粘贴地址并开始画面传来后，应用中的第一步会变成绿色，并出现实时预览。

手边没有无人机？使用应用中的用视频文件测试，用一段录好的视频演练整个流程。

方法 A：用推流密钥在 TikTok 直播

如果 TikTok 向你提供了服务器地址和推流密钥，就用这种方法。并不是每个账号都有；如果找不到，请使用方法 B。

  1. 从 TikTok 复制服务器地址和推流密钥在 TikTok LIVE Center 或 TikTok LIVE Studio 中打开推流密钥页面，复制 Server URL（形如 rtmp://push-rtmp-….tiktokcdn.com/game/）和 Stream key。
  2. 添加 TikTok 推流目标在 Stream My Drone 的要推流到哪里？下选择 TikTok，粘贴这两项。密钥保存在系统的凭据保管库中，而不是文件里。
  3. 保持竖屏画面在画面与声音下保持竖屏 9:16开启。完整画面用画面的模糊副本填充空白处；填满屏幕则进行裁切。
  4. 按下“开始直播”本地服务器运行、无人机画面已到达、并选好推流目标后，按钮才会解锁。之后推流目标卡片会显示直播中。
  5. 在 TikTok 上检查直播在 TikTok 中确认推流已被接收并已公开。结束时在应用中按结束直播。

方法 B：不用推流密钥，通过 TikTok LIVE Studio 直播

TikTok LIVE Studio 是 TikTok 官方的桌面应用。你用自己的 TikTok 账号登录，因此它不需要 RTMP 权限——只需要一个摄像头。Stream My Drone 就提供一个，名为 Stream My Drone Camera。

  1. 启用虚拟摄像头在 TikTok LIVE Studio 标签页中按启用虚拟摄像头。在 Mac 上，应用必须放在“应用程序”文件夹中，macOS 会请求一次批准，位置在“系统设置 → 通用 → 登录项与扩展 → 相机扩展”。
  2. 启动摄像头当卡片显示可以启动时，按启动虚拟摄像头。
  3. 在 LIVE Studio 中添加摄像头添加一个摄像头源，选择 Stream My Drone Camera。
  4. 设置声音把该视频源的音频采集设为无，并在 LIVE Studio 中只选择一个麦克风。这个摄像头只传画面，所以你永远不会听到重复的声音。
  5. 开始直播在 TikTok LIVE Studio 中按 Go Live。开播始终由你自己掌控。

Windows 内置虚拟摄像头已在 TikTok LIVE Studio 中测试过。选择“Stream My Drone Camera”作为视频源。使用 OBS 场景直播时，也可以使用可选的 OBS 集成。

TikTok 推荐设置

设置数值原因
方向竖屏 9:16，1080×1920TikTok 观众用手机竖屏观看。
帧率30 fps流畅，且对上行带宽要求低。
码率6 Mbps CBR恒定码率让接收服务器更稳定。
视频编码H.264 High，2 秒关键帧直播接收服务器期望的格式。
构图完整画面没有黑边，也不会丢失画面边缘。

应用会自动使用这些数值；你只需选择方向和构图。每个推流目标请预留至少 10 Mbps 的稳定上行带宽。

无法直播时怎么办

  • 预览一直是空的：遥控器和电脑很可能不在同一网络。让两者连上同一个 Wi-Fi 或热点，并检查 DJI Fly 中的地址。
  • RC 2 上的 DJI Fly 无法开始推流：某些 DJI Fly 版本要求先给遥控器连接麦克风。
  • TikTok 卡片显示“连接失败”：重新复制服务器地址和密钥——密钥可能过期或被重置。
  • LIVE Studio 中找不到摄像头：先启动虚拟摄像头，再重启 LIVE Studio，让它重新读取摄像头列表。
  • 画面是 720p：遥控器通常发送 720p。应用显示的是真实输入分辨率，不会假装它是原生 1080p。

常见问题

没有推流密钥，能用 DJI 无人机在 TikTok 直播吗？

能。使用 TikTok LIVE Studio，并选择 Stream My Drone Camera 作为摄像头源。你用自己的账号登录 LIVE Studio，因此不需要服务器地址或推流密钥。

为什么我没有 TikTok 推流密钥？

TikTok 只向部分账号提供 RTMP 推流密钥，规则因地区而异，也会随时间变化。没有密钥时，TikTok LIVE Studio 是替代方案。

能同时直播到 TikTok 和 Instagram 吗？

能，只要两者都有推流密钥。Stream My Drone 只编码一次画面，再发送到每个已启用的推流目标；一个目标失败不会影响其他目标。

Stream My Drone 会登录我的 TikTok 账号吗？

不会。它从不登录任何平台，也从不替你按 Go Live；它只把视频发送到你提供的地址，或为 LIVE Studio 提供一个摄像头。

Stream My Drone 免费吗？

免费。它以 MIT 许可证免费开源，与 DJI 和 TikTok 没有任何关联。
