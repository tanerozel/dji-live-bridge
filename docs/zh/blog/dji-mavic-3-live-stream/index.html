如何用 DJI Mavic 3、Classic 或 Pro 直播

作者 Taner Özel · 更新于 2026年10月25日

DJI Mavic 3 系列可以通过 DJI Fly 发送实时相机画面，但能用哪种方案取决于遥控器。使用 RC-N1 时，搭配飞行用的手机和电脑接收端；使用 RC Pro 时，搭配另一部运行 Stream My Drone 的手机。带屏的 DJI RC 情况不同：DJI 不支持用它直播。

要点速览

  • 本文适用于消费级的 Mavic 3、Mavic 3 Cine、Mavic 3 Classic 和 Mavic 3 Pro 系列，不包括 Mavic 3 行业系列（Enterprise）。
  • RC-N1 需要用手机运行 DJI Fly；电脑方案让接收工作交给另一台电脑。
  • RC Pro 可以把 RTMP 推流发送到另一部手机或电脑上的 Stream My Drone。
  • DJI RC 可以控制飞行，但不支持 DJI Fly 直播。
  • 请检查 RTMP 画面本身：相机录像画质和遥控器上的实时图传并不决定直播分辨率。

同时确认飞行器和遥控器

对于消费级系列，DJI 在 Mavic 3 Pro 支持常见问题中列出了 RC-N1、DJI RC 和 DJI RC Pro。Mavic 3 Classic 支持页面也列出了这三款。初代 Mavic 3 支持信息列出了 RC-N1 和 RC Pro；DJI RC 常见问题也确认 DJI RC 兼容 Mavic 3 和 Mavic 3 Cine。这些说的是飞行兼容性，并不代表每款遥控器都能直播。

遥控器DJI Fly 运行在哪里直播方案
DJI RC-N1通过 USB 连接的手机由这部手机通过 RTMP 推流到电脑上的 Stream My Drone
DJI RC Pro遥控器自带屏幕通过 RTMP 推流到另一部运行 Stream My Drone 的手机，或推流到电脑
DJI RC遥控器自带屏幕不支持 DJI Fly 直播

不要把 DJI RC 与 RC 2、RC Pro 与 RC Pro 2 混为一谈。Mavic 4 Pro 的遥控器方案并不说明它与 Mavic 3 兼容。Mavic 3 行业系列（Enterprise）和热成像版使用另外的产品和应用流程，不在本文范围内。

在你自己的软件上确认 RTMP 菜单和音频

使用支持直播的遥控器时，先完成对频并打开 DJI Fly 的相机界面。在 GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP 下查找。如有需要，更新飞行器、遥控器和 DJI Fly，然后在规划直播活动前再次检查菜单。

DJI 的直播指南要求从 DJI Fly v1.16.0 起在 RC Pro 上连接麦克风；RC Pro 搭配 Fly v1.18.0 或更高版本时，RTMP 只支持 720p。RC-N1 则取决于所连手机上的可用设置。请实际确认这些设置，不要照搬过时的 1080p 教程。

Mavic 3 搭配 RC Pro：用手机接收直播流

  1. 在另一部手机上安装 Stream My Drone从 Google Play 或 App Store 下载。让 DJI Fly 在 RC Pro 上保持打开，由手机接收并转推它的视频。
  2. 让遥控器和接收端连接同一网络使用可以上网的 Wi-Fi。在户外时，负责接收的 Android 手机也可以同时开热点。选好网络后再打开 Stream My Drone，在 iPhone 上按提示允许访问本地网络。如果更换了网络，请重新确认显示的地址。
  3. 在 DJI Fly 中填入接收地址复制 Stream My Drone 显示的完整本地 RTMP 地址。在 DJI Fly 中打开 GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP。按你所用版本中的字段填写：要求分别填写地址和密钥的界面，与要求填写完整 RTMP URL 的界面不同。不要把 YouTube 或 Instagram 的密钥加到本地接收地址上。菜单的详细说明见 DJI Fly RTMP 教程。
  4. 开始本地推流并检查声音在 DJI Fly 中开始直播，确认 Stream My Drone 中出现了实时变化的画面。在地面测试时，检查遥控器上选择的麦克风，并在平台上试听。有画面却没有可用的声音，起飞前排查要容易得多。
  5. 添加推流目标并开播支持时直接连接平台账号，否则在 Stream My Drone 中填写当前的服务器地址和推流密钥。开始转推并打开平台控制台。完成平台单独要求的“开始直播”步骤，然后确认观看页面确实正常。

负责接收的手机与遥控器是两台独立设备。手机转推会保留收到的视频原样；预览裁切或模糊背景并不会生成新的竖屏直播。在 iPhone 上，设置期间请让应用保持打开；切到后台后能否继续接收取决于画中画。

Mavic 3 搭配 RC-N1：用另一台电脑接收

使用 RC-N1 时，让 DJI Fly 在通过 USB 连接遥控器的手机上保持打开。RC Pro 也可以推流到这个电脑接收端。在 Mac 或 Windows 电脑上安装 Stream My Drone。电脑通过局域网接收 DJI Fly 的 RTMP 画面；这种方案不使用 HDMI 采集，也不通过 USB 把遥控器当作摄像头。

  1. 复制电脑的本地 RTMP 地址让电脑和运行 DJI Fly 的设备连接到同一网络。在 Stream My Drone 中复制“连接无人机”下方的地址。rtmp://192.168.1.20:1935/drone 只是示例，请使用应用实际显示的地址。
  2. 开始推流并确认接收在 DJI Fly 中填入该本地地址并开始推流。如果防火墙询问，请允许应用在专用网络上接收连接。设置平台之前，先确认预览画面在动。
  3. 选择输出并启动推流目标选择横屏或电脑版的竖屏布局，然后添加平台的服务器地址和密钥。开始输出，确认平台已收到画面，并完成平台的开播步骤。如果要同时推多个目标，请先确认总的上传带宽需求。

账号是否具备资格由平台决定。两款应用都不会提供推流密钥，也无法绕过平台的权限要求。在电脑上配合兼容的直播软件时，Stream My Drone 还提供虚拟摄像头。本地预览只能证明已收到画面；观看页面正常才说明已经开播。

观众实际能看到什么分辨率？

Mavic 3 系列的高分辨率相机录像和遥控器上的 O3+ 图传，与 RTMP 编码器的输出是两回事。编码器没有发送的细节，接收端也无法找回。请检查接收到的视频尺寸和推流目标的播放画质，不要把飞行器的录像规格当作直播规格来承诺。

这一点对 Mavic 3 Pro 的多颗镜头尤其有用：开播前在接收端测试你打算使用的镜头和构图。更改相机或录像设置并不能代替检查输出画面。如需竖屏直播，电脑版 Stream My Drone 可以把画面裁切或缩放成竖屏输出；手机应用则按收到的原样转发视频。

  • 区分本地接收和互联网上传。遥控器必须通过局域网连上接收端，而接收端需要有足够的上传带宽供所有推流目标使用。
  • 上传需求要累加计算。两路 5 Mbps 的推流输出合计需要约 10 Mbps 上传带宽，每小时约消耗 4.5 GB（不含开销）。测试时先只推一个目标。
  • 既要看也要听。检查遥控器或飞行手机上选择的麦克风，然后在平台上试听。不要以为飞行器的相机画面会带有可用的机载声音。

Mavic 3、Classic 与 Pro 直播问题排查

  • DJI RC 没有 RTMP 菜单：这是官方说明的限制，即使这款遥控器能控制你的飞行器也一样。Stream My Drone 无法为 DJI RC 增加直播功能。请使用本文中兼容的 RC-N1 或 RC Pro 方案。
  • RC Pro 无法开始推流：检查麦克风连接和 DJI Fly 的提示，然后确认当前的 RTMP 设置。
  • RC-N1 所连手机断开：先确认 DJI Fly 仍显示与飞行器连接，并检查 USB 线，再排查接收端。
  • 无法连上接收端：网络变化后，重新复制当前的本地地址。避免使用有设备隔离的访客 Wi-Fi，并检查电脑防火墙。在飞行设备上填 localhost 指向的是该设备自己。
  • 画面已到达，却没人能看到：开始向推流目标输出，确认平台凭据是当前有效的，并完成平台的开播步骤。仅有接收端预览并不会发布直播。

常见问题

部分套装附带的 DJI RC 能让 Mavic 3 Pro 直播吗？

DJI RC 可以控制 Mavic 3 Pro 飞行，但 DJI 不支持用这款遥控器直播。要使用本文的 RTMP 方案，请使用兼容的 RC-N1 加飞行手机，或兼容的 RC Pro。

本文也适用于 Mavic 3 Classic 和 Mavic 3 Cine 吗？

适用，前提是上文所述的消费级机型和兼容的遥控器组合。本文不涉及单独的 Mavic 3 行业系列（Enterprise）或热成像版流程。

不用电脑，能在手机上接收 RC Pro 的画面吗？

可以在同一局域网中的另一部手机上使用 Stream My Drone，同时让 DJI Fly 在 RC Pro 上保持打开。把应用的接收地址填入 DJI Fly，并在 Stream My Drone 中设置平台。

RC-N1 的飞行手机能同时作为接收端吗？

那部手机已经在运行 DJI Fly 控制飞行。本文使用另一台电脑上的 Stream My Drone，让飞行应用可以一直保持打开；本文不假定一部手机能同时兼顾飞行和转推。

为什么旧的 RC Pro 教程显示的分辨率更高？

DJI Fly 的功能会随软件版本变化。请检查遥控器当前的设置和官方直播指南，然后查看实际收到的视频，不要依赖录像规格或过时的教程。

平台的推流密钥要填进 DJI Fly 吗？

在这种转推方案中，DJI Fly 里填的是 Stream My Drone（手机或电脑）显示的本地地址。平台的服务器地址和推流密钥填在接收应用的推流目标设置中。
