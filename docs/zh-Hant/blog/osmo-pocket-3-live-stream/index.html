Osmo Pocket 3 如何直播到 Instagram 和 TikTok

作者 Taner Özel · 更新於 2026年10月3日

Osmo Pocket 3 能從 DJI Mimo 透過 RTMP 直播，最高 1080p。單靠 DJI Mimo，只能直播到 Facebook、YouTube 或某個 RTMP 位址。把這路 RTMP 串流送到你電腦上的 Stream My Drone，Pocket 3 也能在 Instagram 和 TikTok 開播，還能同時直播到多個平台，或成為 Zoom、OBS 和 TikTok LIVE Studio 的無線網路攝影機。

重點整理

  • 在 DJI Mimo（1.2.20 或更新版本）中，Pocket 3 能以 480p、720p 或 1080p、30 fps、最高 6 Mbps 進行 RTMP 串流。
  • Pocket 3 會自己連上 Wi-Fi 網路；請讓它和執行 Stream My Drone 的電腦在同一個網路。
  • Stream My Drone 會同時把串流以 RTMPS 轉送到 Instagram，以及轉送到 TikTok 和任何 RTMP 平台。
  • 為 Instagram 和 TikTok 輸出 1080×1920 直向畫面；收到橫向畫面時，空白處以模糊背景填滿。
  • 內建的虛擬攝影機能把 Pocket 3 變成無線網路攝影機，不需要用 USB 線接到電腦。

設定 Pocket 3 直播

  1. 開啟 Stream My Drone在 Mac 或 Windows 電腦上安裝 Stream My Drone，記下它顯示的位址，例如 rtmp://192.168.1.20:1935/drone。
  2. 把 Pocket 3 連上 DJI Mimo更新 DJI Mimo 和 Pocket 3 韌體，連接相機並開啟直播選項。
  3. 選擇 RTMP 和 Wi-Fi 網路選擇 RTMP 作為平台，並挑選 Pocket 3 要連的 Wi-Fi：與電腦相同的網路，或兩者都已連上的熱點。
  4. 輸入位址並開始輸入 Stream My Drone 顯示的位址；Wi-Fi 允許的話選擇 1080p、6 Mbps，然後開始。畫面會出現在 App 的預覽中。
  5. 在所有平台開播加入 Instagram、TikTok、YouTube 或任何 RTMP 伺服器；Instagram 和 TikTok 請保持直向 9:16，然後按下「開始直播」。

能這樣做的 DJI 相機完整清單，請見 Osmo 相機教學。

創作者怎麼用它

  • 邊走邊聊的直播。雲台讓你移動時畫面依然穩定；同一路串流可以同時送到 Instagram 和 TikTok。
  • 活動與市集。用一台小相機，就能把講座、音樂會或攤位直播到多個平台。
  • 無線桌面攝影機。把 Pocket 3 架在腳架上，在 Zoom、Meet、OBS 或 TikTok LIVE Studio 中選擇 Stream My Drone Camera。Pocket 3 也能當 USB 網路攝影機，但這種方式不需要任何線材。請見網路攝影機教學。
  • 邊直播邊錄影。Stream My Drone 會在串流送出的同時，在電腦上錄下來。

最佳設定

設定建議原因
DJI Mimo 中的解析度1080pDJI Mimo 直播提供的最高解析度。
DJI Mimo 中的位元率6 Mbps明顯比 3 Mbps 清晰；只有 Wi-Fi 吃不消時才調低。
Stream My Drone 的輸出Instagram 和 TikTok 用直向 9:16手機都是直向觀看；1080×1920、30 fps。
網路5 GHz Wi-Fi 或附近的熱點相機到電腦的連線承載整個串流。

無法直播時怎麼辦

  • Pocket 3 無法連線：相機和電腦在不同的網路上，或訪客網路把它們隔離了。
  • 沒有直播選項：把 DJI Mimo 更新到 1.2.20 或更新版本，並更新相機韌體。
  • Instagram 拒絕串流：每組 Instagram 金鑰只能用一次；請在 instagram.com 建立新的直播並更新金鑰。
  • 畫面卡頓：在 DJI Mimo 中降低位元率，或更靠近路由器。

常見問題

Osmo Pocket 3 可以直播到 Instagram 嗎？

只靠 DJI Mimo 不行。透過 RTMP 把它串流到 Stream My Drone，它就會以 1080×1920 直向畫面透過 RTMPS 轉送到 Instagram。

Pocket 3 直播的解析度是多少？

DJI Mimo 提供 480p、720p 或 1080p、30 fps；1080p 時可選 3 或 6 Mbps。

可以同時把 Pocket 3 直播到 TikTok 和 YouTube 嗎？

可以。在 Stream My Drone 中加入兩個目的地；畫面只編碼一次，再分別送到每個目的地。

可以把 Pocket 3 當成無線網路攝影機嗎？

可以。串流送到 Stream My Drone 後，啟動虛擬攝影機，並在你的視訊 App 中選擇 Stream My Drone Camera。
