Siaran drone DJI tanpa mengatur NGINX dan OBS

Oleh Taner Özel · Diperbarui 3 Oktober 2026

Cari cara memasukkan drone DJI ke OBS, dan sebagian besar panduan dimulai dengan cara yang sama: pasang server RTMP NGINX, ubah konfigurasinya, buka firewall, arahkan DJI Fly ke sana, lalu tarik siarannya ke OBS sebagai media source. Cara ini berhasil, tetapi sudah seperti proyek server kecil. Stream My Drone menggabungkan server RTMP, pratinjau, enkode, dan output ke platform dalam satu aplikasi — dan tetap bisa menyerahkan gambar ke OBS kalau Anda mau.

Ringkasnya

  • Resep klasiknya adalah DJI Fly → NGINX dengan modul RTMP → media source OBS → satu platform.
  • Artinya memasang server, mengubah nginx.conf, mengizinkan port 1935, dan menyusun scene secara manual.
  • Beberapa platform sekaligus memerlukan plugin OBS atau layanan cloud; kanvas vertikal memerlukan pengaturan tambahan.
  • Stream My Drone menerima DJI Fly secara langsung dan menyiarkan ke beberapa platform, vertikal atau horizontal, tanpa memasang apa pun lagi.
  • Jika tetap ingin memakai OBS, Siapkan scene OBS membuatkan scene DJI LIVE berisi siaran drone untuk Anda.

Resep NGINX + OBS yang biasa

  1. Pasang server RTMPNGINX dengan modul RTMP (di Windows sering berupa paket siap pakai), atau server RTMP lain.
  2. Ubah konfigurasiTambahkan blok rtmp dengan application seperti live ke nginx.conf lalu jalankan servernya.
  3. Buka firewallIzinkan koneksi masuk di port 1935 dan cari alamat lokal komputer.
  4. Arahkan DJI Fly ke sanaMasukkan alamat seperti rtmp://192.168.1.20/live/drone di bawah Live Streaming Platforms → RTMP.
  5. Tarik ke OBSTambahkan Media Source dengan alamat yang sama, atur ukurannya di kanvas, lalu isi URL stream dan kunci OBS untuk platform Anda.

Setelah itu, setiap perubahan harus dilakukan manual: jaringan baru berarti alamat baru, platform kedua berarti plugin atau layanan relay, dan siaran vertikal berarti kanvas kedua atau profil terpisah.

Pengaturan dengan satu aplikasi

  1. Pasang Stream My DroneUnduh untuk macOS atau Windows; FFmpeg dan server media sudah ada di dalamnya.
  2. Salin alamat ke DJI FlyAplikasi menampilkan alamat seperti rtmp://192.168.1.20:1935/drone. Masukkan di DJI Fly pada GO FLY → ••• → Transmission → Live Streaming Platforms → RTMP.
  3. Tambahkan platform AndaInstagram, TikTok, YouTube, Facebook, Twitch, Kick, atau server RTMP mana pun, masing-masing dengan URL dan kuncinya.
  4. Tekan MULAI SIARANGambar dienkode sekali lalu dikirim ke setiap tujuan yang aktif.

Jika Anda tetap ingin memakai OBS

OBS tak tertandingi untuk scene, overlay, dan transisi. Stream My Drone tidak menggantikan itu — yang digantikannya adalah bagian NGINX. Aktifkan OBS WebSocket (Tools → WebSocket Server Settings), hubungkan di tab Lanjutan aplikasi, lalu tekan Siapkan scene OBS: aplikasi membuat scene bernama DJI LIVE yang sudah berisi siaran drone, disesuaikan dengan kanvas horizontal atau vertikal.

Untuk panggilan di Zoom, Meet, atau Teams lewat OBS Virtual Camera, lihat panduan webcam.

Pertanyaan

Apakah saya perlu NGINX untuk menyiarkan drone DJI ke OBS?

Tidak. Stream My Drone memiliki server RTMP sendiri; dengan Siapkan scene OBS, aplikasi juga memasukkan siaran drone ke OBS tanpa NGINX.

Apakah saya perlu OBS untuk siaran drone DJI?

Tidak. Stream My Drone menyiarkan langsung ke Instagram, TikTok, YouTube, dan platform lain. OBS bersifat opsional untuk scene dan overlay.

Apakah cara NGINX lebih buruk?

Cara itu berhasil dan fleksibel, tetapi Anda harus merawat sendiri server, berkas konfigurasi, dan scene OBS, serta multistream atau video vertikal memerlukan langkah tambahan.

Berapa biaya Stream My Drone?

Gratis. Aplikasi ini gratis dan bersumber terbuka di bawah lisensi MIT.
